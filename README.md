# 知途研究 · Pathwise Research

**从未来十年的变化，反推今天的学业与职业选择。**

我们关心的不是“现在什么专业最热门”，而是：一个学生完成几年学习、进入职场时，产业在做什么、哪些工作正在改变、什么能力还有价值，以及原来的路走不通时能否转向。

为此，项目以 **政策、产业变迁、人口结构变化** 为三条主线，研究中国未来十年的职业入口、成长和转换条件，再连接高考志愿、专业学习、院校培养与个人选择。

**当前进度（2026-10-26）：完整研究框架已通过独立审核并随 [PR #94](https://github.com/mythpan1/pathwise-research/pull/94) 合并。接下来是按框架整理既有成果、识别覆盖缺口并分批填充，不再把方法试水当作项目终点。** 框架完整不等于行业资料已经填满，更不等于未来预测已经被现实验证。

## 一、为什么不能只查专业、学校和招聘信息

今天的招生目录与招聘岗位是当前状态，不能单独回答几年后的选择问题。

同样是产业增长，新增业务可能需要增员，也可能主要靠自动化或外包；同样是行业收缩，有的入口减少，有的维护、改造或转向任务仍然存在。政策写“支持”并不直接等于某专业利好，技术突破也不直接等于出现大量新人岗位。

因此，我们先研究变化怎样传导，再研究教育怎样连接工作，而不是先定一个职业清单，再去寻找支持材料。

项目最终要回答四类实际问题：
- 哪些职业入口值得提高关注，哪些单一出口的风险正在上升？
- 哪些能力可以在多个行业和任务之间迁移，迁移的条件与成本是什么？
- 哪些专业、院校和训练路径真正有助于形成这些能力，而不只是名称相近？
- 对具体学生而言，哪些路径可进入、可承担、值得投入，什么情况下应调整？

## 二、三条主线各自研究什么

### 政策：为什么提出、通过什么工具、改变谁的行为

不只摘录政策口号，也不只追最新文件。沿着同一个问题，比较历次目标、工具、适用对象、资源投入、执行和反馈。

重点是：政策怎样改变企业或公共机构的收益、成本、资格、资源和退出选择，再改变产业活动与工作任务。

“十五五”规划、长期战略、部门与地方文件、执行材料，以及《求是》等文章都可提供入口，但作用不同：规划和文章帮助理解方向与问题，具体工具及执行材料帮助判断作用对象和落实条件。专家解释不能自动当成执行规则，文件发布也不能自动当成效果。

教育人才政策保留辅助价值。服务学业规划，不意味着只研究教育政策；产业政策对工作变化的传导往往同样重要。

### 产业变迁：一条价值链怎样形成、扩散、迁移或退出

连续追踪技术工艺、产品用途、客户需求、成本、生产组织、上下游关系与能力迁移。

不只研究新技术，也研究成熟产业的改造、集中、外包、收缩与退出。研究对象是一条产品或服务链的变化，不是一条新闻或一张“通用能力”清单。

例如，看到垃圾处理企业出海，不只讨论海外事件，还应追问国内环保产业的能力、需求和竞争状态，以及设备、运营、维护、资源循环等环节怎样影响工作。具体判断仍须有相应依据，不能凭一个事件证明整个产业结论。

### 人口结构变化：谁需要服务、谁提供劳动、何时发生变化

少子化是人口结构变化的一个现象，不等于只研究幼儿园；老龄化也不等于只研究养老。

同时追踪：
- 需求：人口、家庭与地区变化怎样影响实际消费和公共服务使用；
- 供给：哪些队列经过培养、资格和参与选择进入哪些劳动市场；
- 接续：从业者退出、补招、迁移和技能传承怎样改变生产组织。

供给既影响求职竞争，也可能推动企业自动化、外包或改变选址。出生、入学、毕业、退休的时间不同，必须回到学生实际进入职场的年份。

**三条线不是互斥分类，也不是三份报告相加。** 它们各自保持连续对象，在具体主体、地区、价值链与时间上连接。国际环境仅在影响具体机制时作为背景接入，不单列主线，也不要求每个研究都扩展到国际局势。

## 三、怎样把变化接到学业与职业选择

共同的连接思路是：

**变化来源与成立条件 → 产业或服务组织的响应 → 任务及用工安排 → 职业入口、成长与转换 → 能力、培养与资格 → 个人可行路径。**

这不是强制单向流水线。不同问题可以从技术、需求、人口或制度进入，也可以有并行分支和跨期反馈。每个连接都要说明是谁通过什么机制改变了什么，不能只画箭头。

| 层次 | 我们要分清的事情 |
| --- | --- |
| 产业与组织 | 技术可行、工程运行、客户采用、规模扩散不是同一阶段；企业与公共机构也有不同支付和组织机制。 |
| 任务与用工 | 任务增加可能由增员、加班、自动化或外包承担；新增岗位、退出补员、在岗人数和新人入口要分开。 |
| 职业机会 | 入口数量、实际竞争、劳动条件、成长机会和持续性可能不同向，不能压成一个“前景好坏”分数。 |
| 能力与培养 | 需要某种能力，不等于某专业已教会；课程名、实际训练、成果和雇主接受要分别核对。 |
| 个人选择 | 再结合选科、成绩、资格、能力发展、地域、预算、兴趣和价值取舍，比较主路径与备选，而不是给所有人同一答案。 |

行业、职业、专业和院校之间是多对多关系。尚未有稳定职业名称的新任务，可以先研究其内容和承接主体，但不虚构成熟岗位或招聘规模。

## 四、为什么先做思维实验，再搭框架

思维实验是前置研究：一方面检查推导逻辑，另一方面找出后续真正值得收集的信息。

我们不要求每个节点都先有完整实证才思考。可以在明确前提下给出有方向的判断，再到会改变方向、强弱或选择的关键节点求证。反例不是研究失败，它能帮助发现哪条连接需要改、后面应该收集什么。

前期样本带来的方法收益包括：

| 样本 | 学到的研究方法，而非固定职业答案 |
| --- | --- |
| 少子化 | 人口变化按队列传导；收入不等于服务量，在岗不等于新招；入口与求职供给可能不同步。 |
| CO₂ 产品链 | 技术须放进投入、产品出口、客户采购和竞争路线；不同产品及商业化阶段不能混用。 |
| 机器人替代 | 先拆任务，再研究部署、组织和人员安排；任务替代、招聘变化和成长机会不是同一个问题。 |
| 政策样本 | 区分目标、工具、适用对象、执行与结果；从政策条件推到主体响应，再确定取证点。 |
| 视频素材 | 提供不同视角和产业线索；分析要回到产业上下游、工作与培养，不能跟着视频无限发散。 |

这些样本是试水，不是项目的全部研究范围。现已据此形成完整框架；后续应使用并修正框架，而不是不断重做试水来推迟正式填充。样本采用和纸面检验也不证明现实预测已经成立。

## 五、怎样让研究连续，而不是越做越碎

项目采用三种相互连接的记录：

1. **连续研究链**：长期追踪一个政策问题、产业价值链或人口对象，保存历史、当前判断和下一连接。
2. **判断包**：每轮解决链中的一个有边界问题，写清条件、依据、分支及对职业或培养选择的影响，完成后回到原链。
3. **来源与改判记录**：判断能追到原文和版本，新证据能追到被修改的判断及受影响的后续结论。

一篇视频、一份文件或一次搜索是材料入口，不自动成为一条独立研究线。多个任务可以分批执行，但必须回到同一个连续问题。

来源陈述、经核事实、机制推断、未来情景和价值取舍分别记录。原文与摘要不混同；多个报道转引同一原件，不算多份独立证据。推演得到的结果，也不能反过来冒充证明自身前提的独立事实。

改判是选择性的。例如，假设某产品的最终用途商用延后，应重审依赖该用途的专用岗位时点；具有独立客户和条件的中间产品不必同时撤回。但如果两者依赖同一融资来源，相关分支也要重新检查。不能一处变化就全盘推翻，也不能为了保留结论忽略共同前提。

## 六、完整框架以后怎样填充

**先有全局覆盖，再按重要问题深入；不是一次研究所有领域，也不是只研究几个热门行业。**

1. **整理既有成果**：把实验、政策分析和视频素材归入连续研究链，区分可用证据、方法例子、线索与待核内容，不重复做已经完成的试验。
2. **识别覆盖空白**：兼顾实体产业、信息与知识服务、公共和生活服务；同时检查新兴、成熟改造、收缩退出，以及人口、政策和地区时间维度。
3. **决定下一问题**：综合变化的重要性、影响群体、对路径选择的敏感性、关键未知及取证成本，写明优先理由，不按新闻热度或材料数量排序。
4. **深入并连接应用**：研究产业和服务链时同步追踪任务、新人入口和培养，不无限堆积上游资料，把决策端一直留到以后。
5. **持续更新**：新政策、产业进展、人口和培养信息出现后，复核受影响判断与路径，保留旧版本和当时依据。

覆盖目录用于发现遗漏，不是把所有维度机械组合后逐格填满。具体新增任务仍须明确范围、预算和完成条件。

## 八、工作怎样推进、怎样留下可追溯结果

知舟负责目标、总体规划、优先级和整体推进；常规执行复用搜索、分析、审核三个职责会话。每次推进一个有边界的问题，分析作者与独立审核者分离，机械发布和合并不重新裁决研究结论。

成果经 **Issue 定义范围 → 分支与 PR 提交 → 独立审核 → 同 PR 返工 → 精确版本检查与授权内合并**。每个环节保留输入输出版本、来源和实际检查，不能只转述上一环节的结论。

审核通过表示相应论证与记录满足要求，不表示未来已经被证明。哈希用于核对交接内容一致，也不证明执行真实或结论正确。详细规则以[唯一主流程](docs/agent-workflow.md)和 [AGENTS.md](AGENTS.md) 为准。

仓库保持私有。个人资料、凭据、原始日志及未获准上传的原件留在受控位置；既有本地知识库不自动导入。框架采用不自动恢复暂停的巡检、工具测试或无限资料收集。

## English overview

Pathwise Research connects changes in China's policy, industries and population structure to career entry, development and transition, then to education and individual choices over a ten-year horizon.

Its complete research framework has been adopted. The next stage is to organize existing findings, identify coverage gaps and develop evidence-backed research incrementally. Framework adoption is not a claim of complete industry coverage, validated forecasts or deployed automation. Sources, assumptions, alternative explanations and revisions remain traceable.
