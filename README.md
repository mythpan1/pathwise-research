## 四、三层资产物理边界与分批填充铁律

1. **GitHub `main` = 唯一当前态最终版权威底座**：仅存放经 GitHub PR 双关审稿（红队挑刺 + 独立审核，审稿记录留 PR 评论不入 `main`）及用户确认合入的去个案化公共成果。107 篇提纲卡初始状态为 `draft`，按 `Batch 1 → Batch 4` 逐篇核实填充后就地升格为 `active`。
2. **网页版 Deep Research + 长期纯净 Gemini Notebook = 研究过程工作台**：Deep Research 仅作前置宽面侦察；所有入本资料须先落本地受控原料区过“可追溯硬主体”防投毒初筛并贴血统头标后直传 Notebook，过程线索未经回核一手原件不得入库。
3. **本地受控工作区 = 受控数据与私人闭环区**：江苏历年及新增投档/专业分数据、跨年组号拆并明细、真实考生四维约束卡与私人规划产出 **100% 留存本地受控目录**（由 `.gitignore` 与 [scripts/validate_framework.py](scripts/validate_framework.py) 双重硬拦截），严禁上传公开仓库或传入云端 Notebook。
