## 当前研究组织（2026-10-25）

共同目的：理解中国未来十年变化如何影响职业入口、能力和培养路径，服务当前学业及志愿选择。三条主线为 **政策、产业变迁、人口结构变化**，可交叉但各自保持连续研究对象；国际条件仅作相关背景。依据[研究总图](../docs/research-architecture.md)。

- 政策：问题、目标、工具、执行和反馈怎样改变产业活动及资格／培养条件；能源仅是其中一条线。
- 产业变迁：把技术工艺、产品用途、生产组织、上下游及能力迁移连到任务和新人入口，不按视频堆积孤立结论。
- 人口结构变化：同时跟踪需求、供给和人员接续，按队列、地区及目标毕业年传导，不限于儿童教育。

## 复用方式

每个有界任务保持独立记录，并说明承接哪条连续研究链、改变什么判断、下一连接是什么。材料正文和历史版本保留，当前导航区分已采用、候选、历史与待核。本地未推送资料不可见，不代表没有执行。

从[任务模板](../templates/research-task.md)准备，Issue建立后在其正文维护范围与状态；方法、成果、素材与执行日志分开。当前不预建全行业数据库，不启动新实验、重做已完成视频批次或自动采用旧候选PR。

## 高考志愿下端入口

当前以江苏生源为数据建设重点，保留全国在江苏招生院校；具体就业地区由考生条件决定。[专业与职业总索引](admissions/major-career-routing.md)直接连接已吸收的产业、职业和培养单元；[江苏物理类](admissions/jiangsu-physics-reference.md)、[历史类](admissions/jiangsu-history-reference.md)及[一分一段](admissions/jiangsu-score-rank-tables.md)是本地数据入口。上述 2026-10-25 状态及连续研究总览为历史基线，新增单元以索引及实际 PR 为准。

[历史位次推演普通志愿](admissions/historical-rank-planning.md)：按省份、科类与志愿单位比较可比历史数据，形成当年条件估计与冲稳保方案；具体数据和省年规则待按需接入。

[选科与招生渠道路由](admissions/subject-channel-routing.md)：按省份、年份和院校专业要求匹配选科，分别比较普通志愿、强基与综合评价。

[培养与职业连接](admissions/education-career-bridge.md)：通过志愿候选、培养路径和职业入口连接十年就业情景；已有有限真实历史候选的条件比较、共同风险和改判走查，也保留合成示范，尚非个人输入齐备的完整志愿方案。

[机器人与制造业 2036 就业情景](industry/robotics-2036-employment-scenarios.md)：结合已核政策、产业与人口事实和条件推导，连接培养和职业入口。

[人口与教育资源调整的 2036 职业情景](industry/education-2036-employment-scenarios.md)：2026-11-07本地修订以全国初中2026、高中2029学龄人口预测峰及到2035的路径，实质下调仅据年龄组继续扩张或当前短期增长给2031/2034中学新人岗位托底的预期，不只提示学前风险；2036/37为条件延伸。招生、在校、教师配置与外招分列，见[全国来源](industry/national-education-cohort-2037-sources.json)和[主张](industry/national-education-cohort-2037-claims.json)。

[南京队列与师范/法学地方校正](industry/nanjing-education-cohort-timing-2037-choices.md)：南京2029初中/2032高中入学预测与全国年龄组总量不同口径；保留玄武真实本科先例，不将其升级为全国就业择时或专业排序。新全国基准同步传至[同一R教医技术比较](industry/demography-education-health-2037-choices.md)及[培养职业桥](admissions/education-career-bridge.md)，不是全国分省岗位或全部教育服务覆盖。


[上电普通能动与自动化本科训练连接](admissions/suep-thermal-control-training.md)：补充课程计划与具体训练活动之间的有限校方证据；区分能动与自动化方向必修，并保留课程映射、方向分流和个人实际获得未知。
