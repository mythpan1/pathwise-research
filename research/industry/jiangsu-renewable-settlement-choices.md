# 江苏新能源结算责任：信息计算与能源互联网怎样比较

研究修订：2026-11-07；固定基线 `e65091e99711d32081d7e55fa404cfdedf5d776f`。本篇只用两份正式文件的已取得内容，区分条款事实、机制推断和未来条件；定位与取得表示见[来源索引](jiangsu-renewable-settlement-sources.json)。

## 1. 当前结论：先查哪种责任，再比较哪种本科准备

**不因电价市场化统一上调信息计算，也不因有机制电价就统一前置工程。先辨项目是直接交易、通过聚合商，还是默认接受市场价格，再查其合同和结算账中，什么损益能由分析或工程行动改变。** 这比旧稿笼统的“承担价格／履约风险且能付费”多了一道可以核实的选择条件。

沿用[原比较](../admissions/jiangsu-power-market-math-choices.md)及[后继入口补充](../admissions/energy-internet-undergraduate-entry-addendum.md)：2025江苏物理上电02组的信息与计算科学、能源互联网工程，均为27151历史观察尺，全组16显示成员接受仍未知。原非用户情景P希望本科先就业、愿比较分析与能源客户方案、考虑国内多市场，但未默认接受任意现场、出差、合同和调配。**信息计算仍是分析准备的起点；能源互联网已有本科建造／技能申请入口，不再以“没有本科入口”支持旧先后。** 两边实际专业接收、可取得训练和可接受新人任务同标准核查，技能目标另须接受。

本篇只增加P内的**江苏风电／光伏发电业务子情景**，不是把P改成只愿江苏，也没有新增江苏招聘。旧异地交易、建造、技能和经验方案样本不搬到江苏，不凭组线、政策或专业名补出个人志愿顺序。

## 2. 已核事实：补的是价差，不是所有收入和未发出的电量

**S1，江苏2025年实施方案及附件1。** 省发改委2025-10-15印发、10月21日公开，载明2026-01-01实施、有效至2030-12-31。附件1适用于直接接入江苏电网的存量／增量风光项目；源网荷储一体化、微网、绿电直连等新型主体及增量配电网内部风光项目的余电被明确排除，不能把所有“能源互联网”业务套进此机制。项目须签差价协议，跨省电量另按相应规则。[S1，附件1第2—4、14、26条]

附件1第23条的官方补差公式是：**差价结算费用＝机制电量×（机制电价－市场交易均价）。** 整月现货结算运行时，参考的是月度发电侧实时市场**同类项目加权均价**；未整月运行时，采用月度竞价同类项目加权均价。它不是承诺把每个项目自己的全部成交收入补至同一值；高于机制价也有回收，且补差与市场电费分别计算后合并账单。[S1，第23—24条]

存量一般机制比例不高于上网量90%，户用分布式光伏／光伏扶贫项目为100%，还须看绿电历史、申报及协议；月度机制量按**实际上网量×比例**。增量同样按实发上网量及固定比例确定，并有年度机制量上限，未用足部分不跨年补足。因此，取得年度规模不等于保证发出这些电，也不等于少发的电量获得同额补偿。这里没有核某项目的竞价价格、执行年限或实际到账。[S1，第5—8、11—16条]

**S2，江苏中长期市场2026版细则。** 对适用的已注册参与者，中长期／绿电合同电能量部分照付不议，偏差交现货结算；已入市而尚无中长期合同者，实发／实用电量按偏差量结算。第113条列出的中长期合约电费只是电费的一项，不能充当完整现货或总收入公式；第116条还把部分损益返还／回收原则留给另行明确。[S2，第111—119条，纸面36—38页]

第121条进一步区分两本账：分散资源按聚合服务合同的电能量价格结算，电源聚合商在批发侧参照发电企业结算，二者电费差归其聚合收益。**批发侧有风险，不等于同样的风险全部留给每个资源项目；也不证明项目已被兜底。** 是否传递价格、偏差与责任，要读实际服务合同。[S2，第121、127条，39—40页]

## 3. 新的区分：平均价格、实际产量与可控行动不能混算

以下是条款支持的机制推断，不是企业损益测算或已发生用工变化。

- **共同均价补差不自动消除项目差异。** 若两个适用项目的机制量、机制价和同类参考均价相同，其补差项相同；若各自市场结算结果不同，不能仅靠这个相同补差项消除差异。差异是否存在、多大、是否还能保留，仍取决于参与方式、合约及其他返还／考核。默认受价项目另按S1规定的同类日均价等口径结算，不能假装每个项目都能自主择时成交或采用同一收入公式。[S1，方案第一节及第23—24条；S2，第116条]
- **价格支持不替代真实出力。** 机制量随实际上网量变化，使可避免的停机、计量和履约问题仍值得检查；但这不证明“多发必然更赚钱”，更不证明控制项目必然划算。正补差与回收时数量变化的含义不同，工程成本、市场收入及调度限制还要一起看。本轮未核现货偏差价格或设备／调度豁免，不能把被限发与设备故障同罚。[S1，第8、23条；S2，第103条]
- **可承担不等于可行动。** 中长期规则允许符合条件的协商、修改、转让和分月调整，但有时限、双方同意及物理能力等边界；提供预测运行信息是一项义务，不是已经核到准确率罚款或新人可独立交易。分析的价值要接到有权限的决策、核对或复盘，工程的价值要接到能实施的可靠性／交付改进。[S2，第14、43、45—46、65、71、74条]

由此，调查顺序应是：**参与方式与协议 → 哪项损益由谁承担 → 什么动作有权且有望改善结果 → 付费和本科分工。** 不是先按“价格波动大”选数学，再去找招聘支持。

## 4. 回到同一P：哪些条件支持先后

| 江苏业务子情景，均须另核是否现实成立 | 当前本科比较与撤回条件 |
| --- | --- |
| 主体保留可管理的交易／合约风险，有合法调整方式，确实支付数据核对、合约曲线分析或结果复盘，并给相关本科新人实际任务；信息计算精确接收及相对训练成立。 | **可继续先核信息计算的分析方向。** 有机制价不能单独否定它；但“预测更准”不是已证利润增量，市场化也不代表数学独占岗位。若责任外移、分析由熟手集中承担，或精确专业不接收，撤销这一业务理由。 |
| 项目相关价格责任依合同主要由其他主体承担，或可用交易行动有限；真正可付费的问题是可避免失量、计量／接口、工程质量与履约，且成本合算、工程本科任务和相对训练成立，对照分析入口较弱。 | **能源互联网的工程分支可前置。** 理由是可处理的问题与新人工作更相配，不是数学理由变弱便自动判工程胜。必须接受实际地点、现场及合同条件；一般建造／技能经历不自动等于售前经验。 |
| 聚合商承担可管理的批发差额，项目侧承担资源可用性与合同履行，两类都有可接受的本科模块。 | 分别寻找承接团队并比较，**不硬排两专业**。这可能只是同一付款链上的不同分工，不构成独立保底；聚合商有收益也不证明增加本科岗位。 |
| 规则与合同尚不能辨明责任，或差额虽存在但没有可接受的本科分工。 | 不用本题给任何一方新增现实优势；保留旧条件准备，或在有限集合内暂无已确认主路径。跨行业分析须有自己的付款与接收条件，不能把“换行业”自动当分散。 |

这些条件以原有双方训练与入口门槛为后续约束，没有新增学校培养事实，也不将某一岗位专业表外推为所有任务的接收。当前应优先比较能解释**数据口径、合同边界与实际系统约束**的准备，而不是押单一补差参数、默认读研或许诺将来必能转岗。

## 5. 毕业时钟、增量与停止处

2027入学且实际四年、如期完成才是2031本科；2037只看实际经历，不保证连续就业。**S1载明有效期止于2030年底，不能成为2031／2037仍获补差的证据，也不能反向断言届时所有项目协议都失效。** 未来应分别检验类似责任安排延续、调整或退出；当规则和合同改变时，重新判断谁承担可管理风险，而不是沿用2026价格、比例或经验要求。

本轮实际前进是：旧稿已有“有收益、能回款、给新人”这一共同门槛；新条款让我们在此前区分**同类均价补差与项目实际结算、实际发电量与年度规模、聚合商与资源项目的责任账本**。同样有价格波动，三种参与方式未必给同一主体留下同一工作，因而改变应先查什么、向哪个承接者找分析或工程入口；不据此宣称既有专业总排序已经反转。

本轮停止在上述条件区分。没有新增招聘、工资、项目利润或2031岗位事实，不补查学校日常培养。既有16成员接受、目标年完整资格与费用等边界不变；2026招生录取采集继续暂停。以后只有适配同一主体／时期的规则或实际合同能改变责任判断时才更新，不继续堆政策标题。
