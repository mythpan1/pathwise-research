# 南京就业情景：南农国贸、工商类、社会学类、风景园林怎样统一排序

研究修订：2026-11-16；基线 `b8bcbf97be1b551475edd9bdc4517d7bb8d4eee4`。重新建立共同前提，不拼接旧两两P／Q排序。来源边界见[索引](jiangsu-njau-nanjing-four-path-synthesis-sources.json)。

**南京一般本科就业的本轮基准序：国际经济与贸易 → 工商管理类 → 社会学类 → 风景园林。国贸为主、工商类为近备；社会学类是服务责任方向备选，风景园林是专门空间设计方向备选。** 前两差距弱，工商类对社会学类的方向相对较明确，社会学类对风景园林仍弱；不是就业率、薪资或录取概率排名。关键理由是：先为已有商业活动中可核验的交付／经营责任做准备，积极看待人口变化带来的服务和空间需求，但不把每种需要都预支成一份专项委托。

## 一、统一基准N：同一城市、同一毕业目标，不虚构考生

- **对象与目标：** 江苏历史类拟2027入学、学校为南农、就业按南京市分析，生源／校址／就业地分开。四类任务均可考虑，优先本科后有薪工作和可说明的责任，不默认考公、读研或执业身份。
- **可行性暂定：** 先把四路径放入条件可行集合，假设资格及必要实践可进入、总成本可承担且暂不主导排序；不等于已证四个南京入口或本校相对培养优势。**位次、英语水平等个人值均未赋定**；工作英语须计成本补足。工商三分流、社会学类四分流仅假设均愿读，不保证结果或同等训练／资格；其余组员接受未知。
- **经济基准：** 现有贸易、制造与消费经营继续产生履约／经营问题，不押普遍扩招；房地产不押快速新建反弹，服务和空间调整先走资源提质、整合与选择性更新。新人可承接有限任务，复杂决定仍可集中熟手。这是依据下述材料的工作假设，非已测2031岗位结构。

这个基准序**不表示历史6766位考生四项都可达**，也不继承旧6527假设考生。2027实际仍四年且按期完成，才约2031本科毕业；2037观察真实毕业、就业和转换经历，不自动算六年在岗。

## 二、为什么这样排：上端变化怎样改变本科投入

### 三组事实改变权重，不是三条新闻各推一个专业

**人口把服务质量与空间适配的权重抬高，但不直接把社会学类排第一。** 江苏2025末60岁及以上常住人口2274万人、占26.70%，2021末为1884万人、22.15%，仅为全省口径。[省老龄公报](https://mzt.jiangsu.gov.cn/art/2026/10/21/art_78624_11845073.html) 南京民政规划则明确当地老龄、少子、高龄、空巢和区域增减分化，提出主城扩优质供给、郊区提质现有床位，以及小偏散设施整合。这提高了服务／场地适配的权重。[南京民政规划](https://www.nanjing.gov.cn/zdgk/202611/t20261113_6039840.html) 推断：需求核实、服务链接和使用反馈增值，但服务运营、调查评估与空间设计是不同购买对象。

**新建压力使风景园林必须靠更明确的存量设计价值，而不是靠建设总量兜底。** 江苏2026年1—7月新建商品房销售面积同比下降15.2%、房地产开发投资下降23.9%，只作省级背景，不套成南京景观订单降幅。[江苏统计局](https://tj.jiangsu.gov.cn/art/2026/8/24/art_85276_11820000.html) 南京已有279.7万元城市体检报告中标，但买的是评估报告，非景观设计或到账；山水比德年报另显示设计按阶段提交、逐级审核并取得客户确认。[南京中标公告](https://jsggzy.jszwfw.gov.cn/jyxx/003004/003004006/20250814/322ceb2764b741fa9fa1fff2c0fdc7c9.html)、[山水比德年报，第16、132页](https://static.cninfo.com.cn/finalpage/2026-04-29/1225229307.PDF) 因此保留存量设计价值，不把设施整合或评估／施工／养护都转成风景园林本科设计费。

**贸易与经营正重组，优先准备的不是手工单证／文案，而是产品、费用和交付责任。** 南京2026—2028跨境行动把传统贸易／制造企业与平台、专业服务和AI应用相连；当地焦点科技案例报道了卖家内容、买家筛选比价、跟单参考工具，效率数字来自企业资料。[行动计划](https://swj.nanjing.gov.cn/njsswj/202609/t20260922_5915521.html)、[南京日报案例](https://www.nanjing.gov.cn/zt/sznjjsqx/cgzs/202609/t20260910_5908068.html) 这些目标／报道同时强化国贸履约与工商经营连接、削弱重复输出的优势，不证明扩招或专业独占。

### 相邻名次的依据与强弱

| 相邻比较 | 当前为什么前置，付出什么代价 |
| --- | --- |
| **国贸略前于工商类：弱差距** | 对“本科先承接可解释的具体交付责任”这个共同目标，产品要求、条款、打样／生产和出运之间的衔接是一条较清楚的准备主线。旧国贸方案有流程训练，南京苏美达历史本科岗位有相应任务支点；独立专业也少一道工商三向分流的不确定性。工商类同样可接商业工作，并非只能国内或不能外贸；其广度是优点，但须把统计、成本与经营练习集中到具体商品／渠道，不能靠“管理”标题兑现。国贸多付工作英语、产品与跨境规则补差成本，故优势只弱，不把一份本地广告当岗位数量优势。[旧贸易卡](jiangsu-history-trade-english-order.md) |
| **工商类前于社会学类：方向较明确、强度中等偏弱** | 基准不押专门公共招考，也不假定所有民生需要都会购买专业调查。经营端已有商品成交、品牌服务费与库存／费用约束，工商类优先练“花了什么、得到什么、为何偏离”，可争取商业组织内的有限经营责任。社会学类的差异识别、服务跟踪有用，但要再穿过合法职责、预算、承接与实际毕业专业；并且四分流不能预填社会学。这是付款对象和准备路径的比较，不是商业现金已证更稳。代价是少投深度调查、制度及服务效果理解；商业岗位开放专业，也意味着跨专业竞争广。[旧社会／贸易卡](jiangsu-njau-social-public-trade.md) |
| **社会学类略前于风景园林：弱差距** | 在“先整合、运营、提质”的基准中，居民差异和服务链接可以发生在现有设施与组织里；改变服务安排未必先要重新设计空间。因此可取得的调查／服务组织训练暂比提前投入一整套专门设计基础与作品更贴近该增量。风景园林的现场、植物材料和空间深化训练有独特价值，且独立专业减少类内分流；一旦付费问题转为难以撤回的空间错误，其价值会越过上述顺序。社会学类仅因愿读四方向，并不自动取得所需社会学训练，这也限制本差距。[旧景观／工商卡](jiangsu-history-landscape-brand-choices.md) |

**公共付款不能借“稳定”一词跳过。** 社区专职、事业招聘和委外员工三种进入／签约结构分开，事业岗不作默认出口。社区专职经费进年度预算、待遇受地方财力影响；南京购买服务要求目录内且先有预算、验收与约定支付挂钩，并有合同期限和预算调整约束。[社区队伍意见，第1、10、12、15项](https://www.zyshgzb.gov.cn/n1/2024/0920/c459388-40324583.html)、[南京财政通知](https://czj.nanjing.gov.cn/banshifuwu/cgzccx/bsfwscztwj/202609/t20260922_5915327.html) “十四五”3600万元公益创投是规划回顾，非2027预算、实付或新人资金；养老预算／服务券两PDF未取得，不填其付款条件。

**主备不是独立抗周期保险。** 国贸与工商类都可能受商业回款、平台集中和初级任务压缩影响；换专业标签不分散同一客户／经营风险。社会服务和空间设计改变的是付费主体、责任与训练代价，也可能共同受地方财力、客户现金和采购节奏影响。四项是报考前备选，入学后不能零成本互换。

## 三、2031争取什么入口，2037凭什么接续

以下是路径推演，非2031岗位预留。旧gad景观岗在重庆、赛夫运营单岗城市未知，不移到南京；资格按实际任务核。

| 路径 | 本科有限投入与约2031的目标 | 到2037的上行／受压分歧 |
| --- | --- | --- |
| **国贸** | 把工作英语与产品、条款、交付记录一起练，争取业务助理、订单／客户协作中的有限责任；不把证书或单证数量当胜任。 | 若能说明规格变化、质量／交期异常怎样处理，可争取更完整产品或客户责任；若长期只录单和改初稿，年限不产生业务判断。跨产品仍须补知识。 |
| **工商管理类** | 不预填电商分流；围绕商品／渠道做统计、费用及结果复盘，争取运营、活动或客户服务中的可核任务。区分服务费业务与持货业务，不能把店铺销售额当雇主利润。 | 若能解释投入、退款滞后、库存或服务交付与结果，才有条件承担较完整经营模块；只做投放点击、素材和报表时，换平台仍可能重补，不因专业名升经理。 |
| **社会学类** | 按实际分流取得调查、证据核实与服务组织能力，争取合资格的社区／社会组织项目支持或调查服务；社会学类不含社会工作，法学等分流也各有自己的资格边界。 | 若能把居民差异、服务链接与后续改善连起来，可形成项目协调／评估证据；若只录档办活动，或项目结束没有接续，需重新匹配承接主体。年限不自动转编、取得社工资格或法律执业资格。 |
| **风景园林** | 投入现场、空间、植物材料、图纸深化及可解释的作品修改，争取指导下的设计配合。付出更连续的专门实践成本，不靠表现图替代可落地方案。 | 若参与阶段审核并能解释使用约束与返工取舍，可接更复杂方案／协作；若项目停滞或只有无解释改图，作品数不等有效经验，不自动成为独立负责人或取得签章权。 |

**AI对四条都改“初稿—核验—责任”的分配。** 国贸的翻译／资料初整、工商的素材／报表有商业工具场景；社会服务整理／初筛、景观图像／方案初稿的影响在此仅作机制推演。应练产品／成本、居民资料与空间约束的核验和异常解释，不是泛泛“会AI”。壹网壹创年报自述入门级与资深人员占比同时提高，说明提效也可重组新人角色；占比不能反算人数，更不证明普遍本科扩招。[壹网壹创年报，第10、17、152页](https://static.cninfo.com.cn/finalpage/2026-03-31/1225058027.PDF)

若经济和预算都承压，2031可能窄任务起步、延后就业或转换，2037只认可实得经验，不按年累加反馈或自动加硕士。费用计学费生活、实践、语言／统计等补差、无薪期与延后就业，不造金额；负担变为主导即重排。今日少子化不直接减少2031既有大学队列，外地／相邻专业竞争和退休后的内部接续仍须考虑。

## 四、不等第一名失败，也能正向反转

共同的南京、本科优先和可承担成本尺度保持；只改变**付费问题及新人实际能承担的责任**，并要求相应训练在实际分流下可取得。

- **服务责任上升：社会学类 → 国贸 → 工商类 → 风景园林。** 若南京可进入工作持续购买的不只是标准活动，而是识别遗漏人群、链接服务、回访并解释改善，相关经费和验收反馈落实，深度调查与服务效果理解就比再加一段通用商业履约更值得先投。国贸和工商仍正常经营也可换序。改变的是基准“以整合执行为主”的责任构成，不是凭老龄数自动加分；若所需训练只在社会学分流可得，还须取得保障，不能把类录取当该保障。
- **空间改造责任上升：风景园林 → 国贸 → 工商类 → 社会学类。** 若存量空间有可接续、支付条件可落实的设计委托，核心损失是通行、遮荫、植物材料或维护约束错误，而且新人能参与连续深化与复核，提前系统学习空间设计可能比多做一轮经营优化更有价值。商业和居民服务路线都仍可行；改变的是基准“服务／资源整合先行”转为“不可轻易撤回的空间改造成为主要付费增量”，不是假定房地产普遍反弹。

若同一南京机会更奖励品类、渠道及净贡献分析，工商类也可前置仍有正常订单的国贸。基准序是当前准备取向，不是永久等级。

## 五、落回南农01：四项同组，不是四个保底

历史入口沿已采用[2025金融财会卡的完整显示表](jiangsu-history-finance-accounting-pair.md)，不重读CSV或升级为官方原件。组记录1922为**最低／最高595／612、最低位次6766、实际录取317，组选科“史+不限”**；12显示成员合计317只证人数对账一致，不证官方完整、计划或2027构成。

| 本文按就业基准排列的四项 | 2025最低分／最低位次／实际录取 | 分配后还要面对什么 |
| --- | --- | --- |
| 国贸（1931） | 596／6527／22 | 独立目标，旧组线不保其专业。 |

其余八项为**会计学、农林经济管理＋、文化遗产、金融学、英语（只招英语考生）、公共管理类（土地资源管理、人力资源管理、劳动与社会保障、行政管理）、日语、投资学**。接受四目标不等接受这八项，也不等两个大类的每个结果都适合相同工作。旧社会学2024级办法已有四志愿递次与容量／成绩竞争机制，不能保证社会学或法学；工商目标届分流也不预填。此处不拿旧名额算个人概率。

**当前行动是分两张表，而非一张混排名：** 就业准备暂按国贸、工商类优先；实际专业志愿只在本人可达、愿读和合资格的集合里按真实偏好列报。旧5797、6527、6766不是未来安全线，不能因为就业序第三就把社会学类当更容易进入的后备。

沿旧核南农2025章程与江苏2026问答，组内分数优先，专业排序表达偏好而不增加分数优先权；服从可能接受其他组员的专业／培养损失，不是只在四项间调剂。不服从也不锁目标，所报不能满足时须承担退档及不能自动补投同批后列平行组的后果；未来转专业不是补救保证。**若有明确拒绝的可能分配结果，须改变整组方案，不能仅把它排后。** 2027正式组、资格和分配规则是执行前门槛，本页不是可提交志愿单。

只保留两项决策级核验：
1. **本人的实际可行集合是什么？** 以目标年正式规则、位次、费用和全部成员／大类结果接受，决定四路径及整组能否进入真实方案。
2. **南京哪种责任值得且能够由自己承接？** 在可得实践与实际分流下，比较可持续付费的履约／经营、居民服务跟踪或空间深化任务，以及训练补差总负担；据此保留基准或启动反转，不再追逐四年后期细节大全。

共同边界：政策／历史广告、预算／中标和收入确认不等实付、录用或目标届训练，未核四路同口径岗位量／个人收益。旧稿各守其前提；本页新增统一基准、相邻差异、共享风险及组内行动，0新增候选或确认入口。2026招生、当前组和CSV继续暂停。
