# 规划框架：合成验收与作者走查

适用：[知识契约](../../docs/planning-knowledge-contract.md)和[扩展模板](../../templates/planning-knowledge-unit.md)。任务 `LOCAL-20261101-planning-framework`；基线 `781c998c597719274fa3734f71b2b2fd16a99910`。

以下学校、专业代号、年度 Y、位次及业务条件全部为**合成输入**。不代表江苏或任何学校真实规则，不作招生建议、数据采集成果或预测回测。验收检查的是文档约束及人工走查结果，不是可运行检索软件测试。真实应用仍核适用原文及权限。

## A01：同号换组、拆分与合并

- 输入：Y−1 学校 S 的组 G01 有甲/乙，Y 年 G01 有丙/丁；旧甲/乙分别进入 Y 年 G02、G03；另一旧组成员又并入 G02。仅掌握旧组投档位次。
- 必须得到：新旧是不同 GROUP 身份；CHANGE 记录拆并与多对多及完整成员差异。G01 同号不建立同序列；旧线只能在注明偏差的参考情景中使用，不能当成 G02/G03 某专业录取线。仍可结合已知条件给新组候选与优先补查项。
- 失败判据：按组代码连续画趋势；合并组只取较有利旧边界；旧组存在即自动认定当年招生。
- 作者走查：契约 3.1、类型 CHANGE、步骤 2–3 可表达并阻止上述自动等同；未来真实映射尚未填充。

## A02：进档较稳，但调剂不可接受、条件接受或成员未齐

- 输入：合成完整组有甲/乙/丙，考生接受甲乙、不接受丙；当前历史比较偏稳。假设该轮学校可在符合资格的组内剩余专业调剂，专业不满足且不服从会退档；该轮退档不再投后续平行志愿。变体：完整成员清单未取得。
- 必须得到：资格、投档、专业分配及退档分阶段。较稳组线不能推出有效保底；分别比较服从（可能丙）、不服从（退档）、改组；征集与后续批次核窗口/资格，不保证可用。已知丙不接受时整组当前不接受；若无已知拒绝但成员未齐，则整组未确认，不能只检查偏爱的两个专业；“以后转专业”仍为有条件路径。
- 条件接受变体：将丙的声明改为“条件接受，年度总费用不超考生明确预算且在指定校区”。甲乙均接受，假设成员完整。声明与条件核验分开，必要条件均须满足，分别检查下表。

| 条件输入变体 | 预期成员/整组判断与保底处理 |
| --- | --- |
| 费用与校区条件均有适用有效依据证明满足 | 丙在已核条件下可接受；整组条件接受。可以继续核招生端保底，但保留条件、依据和使用前复核，不改成无条件接受，也不保证录取 |
| 费用条件已知超预算，校区满足 | 丙当前不可接受；整组当前不接受，不计当前有效保底；可留未来条件变化情景，声明不永久改成拒绝 |
| 费用或校区条件未知，其他条件已满足 | 丙当前未确认；整组未确认，不因“条件接受”四字计入保底；输出最需要核验的条件 |
| 条件原已满足，后续费用更正超预算或校区改变导致条件不成立 | 立即将 ACCEPT 与依赖 PATH 标待复核，撤下原保底判断并重聚合；当前不接受；保留旧判断及旧条件，不覆盖历史 |
| 原依据过期，尚不知道条件是否继续成立 | 当前未确认，暂停原保底判断，待核有效证据；过期不自动等于仍满足或确定不满足 |

- 聚合对照：若丙改为无条件接受且甲乙同样接受、成员完整，整组才是“接受”；若另有一名成员不接受，即使丙条件已满足也按拒绝优先判整组当前不接受。成员缺失且没有已知拒绝时，整组未确认，不能认定条件已全满足。
- 失败判据：服从=保录取；不服从后本轮继续检索下一组；用缺成员的清单认定全可接受；条件未成立/未知就作有效保底；已满足后删去条件；后续失效仍沿用原保底；只满足一项必要条件就认定整体成立。
- 作者走查：3.1、3.3、ACCEPT 模板、步骤 4–5及四阶段表覆盖四态声明、条件核验和上述聚合反例；不从此合成条件推出真实江苏现行规则。

## A03：同分区间跨边界

- 输入：某年某类同分区间为 [20001, 20100]；拟比较的历史边界为 20050，考生未取得可确定同分细序的资料。
- 必须得到：保留区间与同分口径；在边界两侧分别形成条件判断，记录不能唯一排序。用历史比较估计当年机会，不能把“位于区间前端”当事实或保证。
- 失败判据：默认考生位次为 20001、20100 或任意中点，再输出确定梯度/概率。
- 作者走查：步骤 3 与历史指标模板能承接区间及缺口，未新增一套换算公式；真实换算继续用既有一分一段方法。

## A04：资格未知、来源冲突及缺专业级数据

- 输入：选科已知满足；某单科或体检要求待确认；组级历史数据存在但专业级录取数据缺失。变体：两个看似适用规则版本冲突，尚不清楚哪版生效。
- 必须得到：资格标待确认，不从“不知道”推出满足或不符合；保留条件候选。能做组级估计和专业分配条件情景，不能编目标专业概率。冲突保留版本、影响阶段及核验问题；停止无条件资格结论而非放弃全部规划。
- 失败判据：未知自动通过/排除；专业数据少就不提供任何规划；把所有来源混成最新有效规则。
- 作者走查：共同字段、检索 2/4/8、阶段表和停止条件均区分这些状态。

## A05：生源省、就读地、就业地与年份桥梁

- 输入：江苏考生申请位于省 B 且在江苏招生的学校，目标省 C 就业；现有招生记录适用江苏 Y 年，职业研究适用省 D 的 Y＋4。变体：请求者生源省其实为 B。
- 必须得到：原候选按江苏规则筛，不因学校在省外排除；培养按该校届别，职业从 D 到 C 需机制/资格/时间桥梁，不能直接移植。变体明确本阶段 B 生源数据未覆盖，不套江苏录取规则、不宣称 B 考生不可报；可用公共机制部分仍标边界复用。
- 失败判据：学校所在地当成生源省；省外学校被整类剔除；全国上端结论自动等于 C 地目标年职业可进入。
- 作者走查：模块、共同地域字段、关系和检索 1/6 分别保留三个地区与时间；无新跨省采集。

## A06：名称不同的备选共享同一付款约束

- 输入：主路径进入某地公共项目 A，备路径进入承包服务 B，两者职业名称不同，却都依赖同一地方付款方和预算；预算收缩情景下可能一起受影响。
- 必须得到：PATH 用 shares_dependency 标共同风险，不称二者独立保底；比较更独立的候选是否真实可进入，并说明资格、转换成本和时间。暂未找到独立备选时明确剩余集中风险，不伪造第三条路径。
- 失败判据：跨行业标签即判风险分散；招生端“保”被当成职业端“保”；添加未经依据的概率对冲。
- 作者走查：关系表、检索 7、更新传播与 PATH 模板有共享前提字段，衔接既有[路径压力测试](path-stress-test.md)及[产业分析](industry-analysis-workflow.md)。

## A07：版本变更向下游传播，不擦除历史

- 输入：GROUP@r1 被用于 ACCEPT@r1 与 PATH@r1；当年正式更正产生 GROUP@r2，新增不可接受成员并改变选科限制。另有两个 PATH 共用某职业资格 RULE，随后该规则对目标届别失效。
- 必须得到：来源新旧并存，组年度身份不变但修订增加；成员/资格变化触发 ACCEPT 和所有相关 PATH 的对应招生阶段重核。共享资格失效也触发两条路径的培养/职业重核；关系自身版本/状态同时更新，报告标待复核。不相关分支保留须说明没有共享前提；旧输出留存供按当时信息回看。
- 失败判据：只改当前来源链接不标受影响报告；沿用旧接受度；全部结论无差别撤回或把新版覆盖旧预测；过期规则因曾经审核通过仍当现行。
- 作者走查：共同字段、supersedes 与第 6 节定义了直接/间接依赖、状态和使用前检查；本轮未实现自动失效传播器。

## A08：产业增长不等于新人入口更好

- 输入：基准情景假设产出增长，自动化使单位产出用工下降，现有岗位更偏向有经验者；某学校课程名字与产业相近，但实践资源资格和雇主接受尚无证据。
- 必须得到：SCENARIO 分产出、工作量、组织响应和任务变化，ENTRY 单列新人入口及竞争，TRAINING 保留实际训练与可取得条件缺口。可以给有方向的条件判断及替代路径，但不能仅凭产业增长把该专业排第一或断言课程=能力=录用。
- 失败判据：产业增长直接映射专业利好；把“学校有实验室”当学生实际可用；因缺全链实证而拒绝所有条件推导。
- 作者走查：SCENARIO/ENTRY/TRAINING 类型、连接条件与检索 6 阻断上述跳跃；没有验证任何真实行业趋势。

## A09：受控数据不能由派生产物泄漏

- 输入：GROUP 成员来自受限会员 CSV，ACCEPT 含个人条件；某摘要/缓存/执行日志包含原表行或可识别个人信息，独立审核者没有原件权限。
- 必须得到：原件、派生索引、缓存、日志及个人输出继承权限，仓库只存获准方法与必要脱敏指针；未经授权的片段不因是“摘要”就上传。审核报告明确原件未核，不以哈希补充缺失访问，不扩权。
- 失败判据：私有仓库等于可以上传全部个人或购买内容；为审核便利复制原 CSV；摘要或哈希自动被当成公开许可。
- 作者走查：第 6 节与模板明确继承边界。本轮案例没有真实个人资料、学校数据或会员原表；不代表已审计所有历史数据。
