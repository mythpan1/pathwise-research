# 上电核工程与自动化：核电运行准备怎样改变本科路径取舍

## 当前方向：核电已有本科申请窗口，不能再只按专业标签排除

**核工程与核技术应进入具体本科职业比较，不必先假定读研或只能去主控室操纵。** 莱阳2027校招把核工程类、自动化类同时列入运行准备岗；同页通用条件面向2026、2027届本科及以上应届生，未列该岗例外。这支持本科申请窗口，不是单岗学历栏独立明列，更不是录用、岗位授权或持证承诺。[N03]

**若当前目标是同时保留核电运行准备与非核工业测试/控制两条路线，自动化可暂列专业比较在前；若明确更愿投入核设施系统、运行规范及特定厂址的长期训练，且目标项目持续接收相关本科，核工程可反向前置。** 前者依据是本轮核电招聘与既有工业岗位对自动化的双向接收证据，不是全市场就业率比较；后者是任务取向与训练条件成立后的选择，不证明核工程在同一核电岗位录用更占优。核电技术与控制工程只作近邻候选，不能因名称含“控制”就确认归入该岗自动化类。

这里推进的是[旧本科入口桥](jiangsu-three-group-entry-bridges.md)尚未展开的核方向，不改写旧P_S/P_E的历史实验。[R03、R04]**旧卡拒核和R=苏州均为合成假设，不是用户偏好；本轮真实用户对全部16成员、核电/工业任务、厂址、班制、健康核验和其他条件的接受状态一律未知。** 江苏生源、上海就读地与就业地分开；核电样本位于山东莱阳的公司，工业样本在苏州，须作为不同地区的可选路径比较，不拼成同城岗位，也不限定只能在苏州就业。

研究修订日为2026-11-03。沿2027入学、实际学制若四年则2031本科毕业、2037观察职业积累的情景；没有预设六年连续就业。只复用固定旧表摘要，不读CSV、不增院校/招生/课程材料，不形成2027可提交志愿表。

## 2. 政策、项目阶段和招聘，各自补上哪一段

**N01：建设方向不是用工配额。** 国家发展改革委、国家能源局《新型能源体系建设“十五五”规划》（发改能源〔2026〕884号，2026-06-13署日、6月25日公开）第4页提出以三代压水堆技术为主、保持平稳建设节奏，2030年全国在运核电装机达到1.1亿千瓦左右。这是约数规划目标，不是在运加在建、不是新增量或已实现值，不是岗位数；“十五五”目标不能直接外推2037增速。[规划原文](https://www.ndrc.gov.cn/xxgk/zcfb/tz/202606/P020260625612978907651.pdf)

**N02：具体承接与核准已见，时点必须守住。** 电投产融2026-044公告（2026-08-01落款）称公司7月31日获悉莱阳1、2号机组获核准；本期拟建2台CAP1400、单台1543 MW，正文仅称施工准备有序开展。拟设业主“国电投核电(莱阳)核能有限公司”截至公告披露日尚未成立；成立前由上市公司所属“国电投莱阳核能有限公司”推进前期及投资建设相关工作。公告给出未来投资、建设、运营责任的承接安排，没有投资到账、正式开工或投运日期、招聘人数。不能混同两法人名称，也不能把8月的准备状态写成11月最新状态。[公告第1—2页](https://static.cninfo.com.cn/finalpage/2026-08-01/1225452330.PDF)

**N03：运行准备已进入校招，但不等于把项目全链证实。** [河北工业大学承载的2027校招页](https://career.hebut.edu.cn/home/recruitment/content/type/2/id/5444.html)招聘主体是“国电投莱阳核能有限公司”，简介称2022-10-20成立、位于山东烟台莱阳。页面没有新业主名称，不证明新业主已成立或它就是劳动合同主体。页头2026-10-16 10:00是宣讲时间，发布日期未知。

标2027届校招、宣讲时间为10月16日的页面，其发展介绍自称项目已开工建设；应与8月1日公告分列，不能用未核发布日期精确排列工程进展。此为招聘材料的阶段自述，**不能当作已取得首罐混凝土、施工许可或商运节点证据**。也不能因8月只记准备就断言后来未开工。本轮不扩搜后续工程节点，2031、2037运行状态仍为情景条件。

同页运行准备岗专业类别列核工程、能源动力、电气、机械、自动化等；通用本科及届别条件支持相关本科毕业生申请。通用要求还包括主修专业与学历备案一致，计算机、表达、动手和协作能力，以及健康、无酗酒史和长期用药史、无色盲色弱及其他职业禁忌症。这里只转述本公告条件，不替考生作健康判断，不将其当所有核电岗位的统一要求。报名之后仍有筛选、笔面试、体检、综合审议和签约，当前是否仍可投递未核；公告未列该岗独立职责、人数、具体工作地址、班制、培训安排或持证路线。公司所在地不等于已核单岗厂址，倒班若作为职业情景讨论，只能是假设，不能认定该岗已要求或用户愿接受。

**有向传导是：** 全国建设方向提供项目持续推进的背景 → 具体核准和企业责任把建设/未来运行任务落到组织 → 招聘表显示该组织在这份校招中提出运行准备招聘需求，且通用条件提供本科申请窗口 → 只有实际项目进度、预算、录用和带教分工继续成立，才转为2031新人工作与后续积累。前三段已有不同层次的事实；持续至2031、具体工作包及培训落实是待检验推断。未核资金到账和工资支付，不把招聘、拟建规模当作已兑现收入或净增员数。

## 3. 本科筛选、训练和主控室资格是不同环节

| 当前方向 | 已有接收证据与当前可用判断 | 训练和任务缺口，不能冒充学校兑现 |
| --- | --- | --- |
| 核工程与核技术 → 核电运行准备 | N03明列核工程类，支持核工程相关本科作为申请候选；具体毕业专业仍须按雇主主修/备案筛选，未逐字点名上电该专业，也不保证优于同岗其他类别。 | 岗名不等任务书。系统设备学习、运行文件理解、安全规范与异常信息记录可作待核工作/训练问题，**不是该岗已明列职责**；要核新人获分哪些任务、由谁带教及考核。不能把“核工程”自动等于已掌握某堆型运行。 |

工业对照只复用[R02]，本轮未重读两个外部原页：东山精密2026-09-10苏州吴中测试工程师列本科、电气/自动化/测控/电子信息/计算机等，做测试方案和设备、产线程序调试验证、良率与故障处理，要求模数电及至少一门编程；同日昆山自动化工程师列本科及机械/电子信息/自动化等，涉及改造方案、设计/BOM、安装调试、量产移交和设备故障，项目/实习经历优先。校园投递是新人正向线索，具体届别与实际带教未明。它们不是核电岗位，也不是2031持续招聘保证；本轮不据旧样本新增苏州政策或学校结论。

**N04只约束特定主控室人员，不能给所有核电员工加同一持证门槛。** 《民用核设施操作人员资格管理规定》（2021-01-27公布、7月1日施行）第2条针对在主控室操作或指导他人操作控制系统的运行值班人员；第3、6条要求相应执照，操作培训涉及临时授权和监护。第7条核动力厂操作员执照申请学历门槛为大专及以上，同时要求健康、培训及考核合格；**这不是企业必须录用的学历线，更不能用它降低N03本科招聘要求**。[原规章第2—9条](https://www.mee.gov.cn/gzk/gz/202112/t20211214_964075.shtml)

若未来岗位确属上述范围，第20、21、25、27条的系统设备、辐射防护、运行技术规格书、安全文化及笔试/口试/操作考试才进入持证路径。第14、17、23、24、32条另有有效期、再培训、跨设施变更/差异训练及岗位授权维持要求。因此，“本科申请 → 录用受训 → 特定任务授权/持证”不能合并成一步，运行准备岗也不一定最终成为操纵员。本轮未做全部现行法规更新检索，实际就业与资格行动须核届时规则；不宣称这些原件自动适用2031/2037。

## 4. 2031入口与2037职业：什么条件使当前先后反转

以下为**条件情景，不是用户接受声明或未来事实**。共同前提是实际学制、专业筛选、可取得训练和具体就业条件成立；不能只靠政策目标满足。

| 情景及传导 | 当前专业方向与2031入口 | 到2037观察什么；反转或失效条件 |
| --- | --- | --- |
| **A：希望保留两类任务；核电项目仍招相关本科，工业客户也有已付款或可持续回款的测试/改造工作包，且愿交新人。** | **自动化暂前，核工程保留。** 两边都见过类别接收，工业细岗还给出明确任务；核工程当前只核到核侧类别，不能凭想象给它补工业控制资格。 | 看能否形成系统验证、故障复现和异常闭环的实际成果。换行业仍要补产品、设备、标准和雇主筛选；样本覆盖较多不是市场收益保证。若核侧成为明确目标，转N；若工业订单回款和新人分工消失，自动化这项相对理由减弱。 |
| **N：更愿长期投入核设施系统及规范；具体项目的阶段、培训和本科接收持续，核工程可取得的训练更贴合实际系统/运行分工，地点/班制/职务条件可接受；相比之下工业任务并非想要。** | **核工程可前置于自动化。** 理由是培养投入与目标任务集中，不是认为核专业被该岗优先录用。自动化仍为同核侧入口的竞争路线；核电控制只有具体认定和训练匹配后才跟进。 | 看实际分工究竟是运行、设备支持还是其他路径，训练与授权是否形成可用经验。不能按毕业六年保证主管、高级操作员或稳定在岗；跨设施执照训练限制只适用于相应持照人员。项目延后、任务被原队伍吸收或本人不接受具体条件时，下调核方向而非坚持政策押注。 |
| **C：核电项目/校招窗口与2031错位，或地点/职务条件不合；工业测试与改造仍有可接受本科任务。** | **自动化的工业路线反向优先。** 这是已有具体细岗支持的职业备选，不需要把核电必定停建当成前提。核工程转工业控制不能承诺免成本，须另有专业接收和相应训练证据。 | 若工业侧也仅剩重复执行、熟手集中或不可接受现场条件，不能强行保留自动化主案。原项目尚未招2031新人不等行业长期没有核机会，关注真正匹配毕业届的窗口。 |
| **F：两端投资/订单与回款承压，或用工主要由存量人员、标准化工具/外包熟手承担。** | **两方向同时下调，可暂时没有已确认主案。** 建设规模大、存量设备必须运行，都不等于必须新招本科；不强制靠读研、必转专业或另一个同组志愿填空。 | 新公司或外包岗位名不自动分散共同风险；须看不同付款来源和新人分工确已成立。原组其他专业也必须本人接受，不能作为自动兜底。 |

核电项目和一般制造客户不必共享同一笔终端付款，因而在实际接收、地区和转换训练成立时，工业路线能提供不同客户来源的备选；但两端可能共受投资、成本、人才竞争与技术集中影响。没有测出相关性或独立性，不把两个行业名称当已验证对冲。

人口在本题只通过三个可检验条件进入：产业及人口迁移怎样改变负荷位置与产业需求；合格毕业生、外来人才和在职竞争者供给；原队伍退出后是补招、调配、延退还是任务重组。**总人口下降不能直接推出电需求下降，退休人数也不能直接变成核电或工业岗位。** 本轮无相关地区负荷因果、人员年龄结构或2031供需数量，不造净增、缺口或录用概率。

## 5. 这轮改变了什么，下一项只核真正能改判的条件

本轮把核工程从旧合成拒绝设定中分离出来，新增“核工程类/自动化类 + 通用本科条件”的真实申请连接；把全国建设目标落到一个有核准、组织承接和运行准备招聘的具体项目，同时保留工程阶段自述与许可节点、招聘与录用、录用与持证之间的断点。当前能给出A/N/C的有向专业选择，不能据此宣布上电整组已接受或三目标稳录。

下一次有必要推进时，优先核：

1. **同一岗位的实际任务和接收。** 当届具体专业认定、学历/届别是否延续、新人工作包与培训安排，决定核工程、自动化和核电控制能否真正进入及如何排序。若不再接收某方向，就撤回该连接；若只是尚未发布，不写成已取消。
2. **对应毕业窗口的项目与主体。** 后续业主登记、真实工程/许可节点、招聘预算和签约主体，区分原公司、拟设业主及其他承包方。项目延迟不一定消灭准备工作，但会改变招录届别和积累内容。
3. **本人选择与另一端的真实承接。** 单岗地点、班制和职务条件由原文及本人确认；工业客户的付款、项目分工和培训若弱于核侧，按N反转，反之按C。无需先扩全院校、课程或宏观卡。
4. **回到当年志愿时再核进入条件。** 所有16成员接受度、完整招生组、选科/体检/专业分配与历史可比性齐备后，才由专业方向推到组内顺序和组级风险。旧27151及2026规则不能代替2027核验。
