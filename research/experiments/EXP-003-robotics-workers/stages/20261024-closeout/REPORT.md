# EXP-003 前置研究收口：从可替代任务到新人入口

2026-10-24 · 中国2026—2036年职业与培养选择 · [实验入口](../../README.md)

**机器能替代什么，先看具体任务边界。** “焊工”“仓储作业员”是职业名，一个岗位往往同时包含准备、操作、检查、交接和异常处理；机器完成其中一个动作，不等于接手整个任务包，更不等于职业消失。判断单位应是“在什么环境、面对什么物料、按什么质量与节拍，完成哪段动作，异常后由谁接回”。

以下判断维度属于分析工具，并非案例已经逐项测量的结果：环境是否结构化，物料与目标变异多大，动作是否重复，感知和操作能否稳定完成；异常发生多频繁、能否恢复，输出是否可检验，失误代价多高，以及人机交接是否明确。固定工位中的重复动作可作为优先核查对象；换型、非标准物料或异常较多时，应先核机器覆盖范围和人工接回成本，不能预填未来能力。

现有材料可把“工作”拆到下面的程度。“已完整接手某边界任务”仅指来源描述机器完成了所列动作链，不代表独立验证持续无人运行；“只能辅助”也只描述该案例的任务包，不是机器能力的永久上限。

| 既有场景 | 机器接手的边界动作 | 仍需人或未披露的部分 |
| --- | --- | --- |
| Dynamic Group 注塑与配套装箱 | 来源记载机械臂取放、转运至修边或去浇口工装、堆放；装箱单元抓取盒底、放入擦拭巾和盐水、推盒上输送带。可记为已接手这些明确动作。 | 注塑单元仍由人后续处理或检查；装箱仍有人，具体职责、异常恢复和全流程无人化未披露。不能把注塑的人工作业挪作装箱分工。[B-S1：“The solution” L45—50][S1] |
| 中国匿名A厂座椅骨架焊接 | 机器人按设定路径完成焊接，可记为接手这段焊接动作。 | 人装配、夹紧、监看、取出和转移工件，仍有少量手工焊接；焊缝质检、换型与异常恢复的完整分工未知。因此不是整个焊工职业被替代。[CN-R1：r1-a-deployment、r1-a-entry][S2] |
| DHL 的 AMR 辅助拣选 | 自动移动货物，减少人的行走和推重车劳动。 | 对完整拣选任务包只能说辅助；各站点剩余动作未逐项披露，不能据累计拣选次数认定机器人独立抓取、包装或取代整名拣货员。[B-S4：L49—51、65—67][S1] |

因此还须分四层：**技术可行**是特定边界内能完成任务；**经济划算**要计入集成、维护、返工与停机等全成本；**组织可部署**要解决工序衔接、责任、训练与异常接回；**人员结果**才是人时、岗位、调岗和招聘怎样变。前三层也不会自动给出第四层；上述部署叙述不能证明所有条件都满足。最小后续需要是同场景的任务覆盖、失败与人工接回记录，纳入下文第一项收集问题。

**条件主判断：机器人能够可靠部署、包含集成维护与停机等的全成本可接受，且省下的人时未被需求扩张带来的用工增加抵消时，重复操作的新招、补招入口承压；补缺与替代既有劳动可以并存。** 这是两轮材料支持的条件推断，压力方向比全国净岗位数及发生速度更可判断。设备采购、爬坡、人员调整和学生毕业存在时滞，今天未减员不能保证毕业时仍补招。[第一轮“三条推演路径”][R1]、[第二轮“从采用动机走到新人入口”][R2]构成推演起点。

判断必须拆成四件事：**岗位数**看工作量、工时与岗位组织；**人员处置**看转岗、退出及离岗不补；**工资与工作质量**看收入、工时、强度和稳定性；**成长入口**看新人能否获得经验并进入技术任务。省下一项动作不等于撤销整个职业，未裁员也不等于入口稳定。第一轮工厂和仓储商业案例只支持任务分工可变，缺少同产出全流程人时及招聘台账；法国历史研究显示采用者扩张与竞争者承压的关联，不能把赢家增员当全行业补偿。[B-S1：L34—50；B-S4：L65—92；T4：§I—III][S1]

两轮讨论对原假设作了三项收窄。第一，**危险、难招是采用动机的候选解释，不能证明必然优先自动化。** 难招有历史陈述支持；危险暴露本身不能识别采购原因，还须满足可靠性、成本和组织条件。第二，**社会稳定约束不能保证无人退出。** 中国历史材料既有省工、缺员与继续招聘并存，也有协商补偿离职及解雇记载，直接限制“只补缺、不替代已有工人”的强说法。它们来自同一项2018年广东田野及2022年管理者报道，并非2026现状或独立用工因果台账。[第二轮“历史材料怎样修正假设”][R2]；[CN-R1：r1-a-personnel、r1-b-entry-personnel；CN-R2：r2-motive][S2]

第三，**收入分配与消费回流不足可能抑制需求，机器不消费不等于资本停止流动。** 条件链是：劳动收入损失落在消费需求较强的家庭，收益集中，其他就业、降价、投资、分配或外需又未足量及时补回需求，则订单、扩产和招聘承压。工资率、劳动报酬总额、劳动收入份额不能互相替代；投资和利润分配仍可发生。法国材料未检验家庭消费因果，额外消费模型原文未取得，因此这仍是条件机制，不是已证实的中国衰退预测。[第二轮“购买力反馈与培养选择”][R2]；[B2-T4-reuse：§I—III、Table 1][S2]

对今天的培养选择，应上调**纯重复操作、长期只做辅助工作且没有训练通道**的入口与转向风险。优先比较能否接触真实工艺、测量质量、定位故障、验证修正，以及带薪训练、导师和实际技术入岗记录。历史案例中辅助岗位与专门维修分开，说明“在机器人旁工作”不足以证明技术成长；维修雇主和新人通道仍未知。[CN-R1：r1-a-entry、r1-b-maintenance；CN-R2：r2-ownership][S2] 设备商、集成商或少数跨线专家承接任务是待检验的组织分支，不能假定设备增加便带来大量维修净岗位。这是培养比较方向，不能替代具体院校、资格与岗位核验，也不形成热门专业排名或就业保证。

未来仅保留四项最小收集问题；以下“增强/削弱”均指对应风险判断，具体台账缺失不妨碍本次前置研究收口：

1. **同产出、同质量的全流程人时和人员流向。** 先核动作覆盖、失败与人工接回，再计入辅助、维护、返工及停机，并区分转岗、退出、临时工减少和补招。人时持续下降且新人补招减少，增强入口压力判断；人时未降或成本抵消省工收益，削弱直接替代判断。
2. **同一目标毕业年、地区和资格的新人实际招聘岗位与合资格供给。** 核实际新招加补招，去重并区分熟手岗、内部转岗与外包；比较能且愿申请的人。新人岗位收缩快于供给，增强竞争压力；供给下降更快且岗位质量可接受，则削弱压力。全国人口或就业存量不能作该分母。[第二轮“竞争要比较同一市场的两侧”][R2]；[B2-C1、B2-M1（§1.2、Chapter 6；非正式方法稿）][S2]
3. **训练通道及技术任务归属。** 核谁雇用、谁训练、谁能入岗及训练后去向。辅助工长期隔离于排错和工艺任务、技术工作只由熟手承接，增强成长入口风险；持续带薪训练并有新人技术入岗结果，则削弱风险。
4. **需求回流。** 核收入归属、实际购买力、订单来源与持续性。劳动收入损失未被补足、终端订单疲弱且扩张主要靠抢份额，增强需求反馈压力；可见的新就业、分配、降价或投资外需带来足量持续订单，则削弱压力。单厂收入上涨不足以判定行业回流成立。

方法收益只作有限归纳：少子化提醒区分需求规模、工作量与招聘；CO₂产品链提醒先拆产品用途、全流程条件和产业环节；机器人进一步拆开任务、人员调整与成长入口。人口、政策、国际环境仍是研究主线，三个实验不与三条主线机械对应。[既有方法说明][M] 这里不搭总框架，也不宣称全项目完成。

本次冻结既有两轮依据，新增业务调用为 **0**，未新取现实材料或新编数字。历史中国及海外案例用于识别机制，不能硬外推中国未来十年；来源索引保存的是解析范围与留存定位，不代表完整原件已核验。**前置研究至此形成可用的方向、选择含义和改判点，现实预测仍未完成。** 本稿交独立审核；不合并、不自动启动下一轮调查。
