# 研究覆盖与推进
当前接口盘点：2026-11-01；下方 1–4 节保留 2026-10-26 的覆盖基线。用途：完整框架的覆盖规划与缺口导航，不是全行业研究完成证明。任务授权与实时执行状态以 Issue 为准；建立前可按主流程使用 LOCAL 标识，不另造并行任务状态。

优先级 P0 是会改变可报性及保底的基础，P1 是让上下端真正汇合，P2 是已有组合后的持续维护；不是按新闻热度排序。F1–F6 的依赖、交付和验收见[建设计划](../docs/roadmap.md)。这是后续候选表，不自动授权采集、个人资料读取或连续派工。

后续每项覆盖摘要至少写：省年/类别/渠道/批次/轮次、学校/组范围、就业地区/时间、已核对象集合、未核/无权限/不存在证据的区别、固定输入版本、关键缺口及其决策影响。仅在有完整分母时报告覆盖比例，不能用文档数量推“覆盖率”。

## 1. 组织方式
三条主线各自连续，同时用产业/公共服务、人口、政策环节、职业培养及时间地区检查覆盖。行业、职业、专业目录用途不同，使用具体分类时注明版本，不把下列设计用分组冒称官方分类。
每新增一个专题，说明所属连续链和对决策的意义。相同材料可多维引用但不重复计为独立证据。

## 3. 完整范围的待评估视图
下列是待评估的覆盖维度，不是本轮新增调查清单：
- 实体产业与配套：农业食物、能源资源、材料化工、装备制造、建设及基础设施、物流商贸、环保循环。
- 信息与知识服务：数字基础设施、软件及信息服务、研发设计与专业服务。
- 公共和生活服务：教育、健康与照护、公共治理和公共服务、文化及生活消费。
- 每个相关领域同时关注：新兴、成熟改造、扩散、收缩、退出及地区迁移；行业边界不清时允许多标签并标映射依据。
- 跨行业任务和能力：按实际职责连接多个行业，不另外制造一条脱离产业的“通用能力主线”。
- 人口维度：需求、供给、接续，队列、迁移、参与、家庭和地区。
- 政策维度：问题历史、目标、工具、执行、反馈，而非只收当前政策标题。
- 决策维度：任务归属、应届入口、成长转换、能力培养、资格及个人适用。

以上分组可随覆盖工作调整，本版不做就业规模排序、不声称穷尽分类。

## 4. 后续填充的实际顺序
1. 按三条主线给既有成果建立连续链归属和缺口索引，引用固定成果，不重跑方法试验。
2. 对尚未评估的领域形成简明覆盖概览，说明“已有哪些材料、可能改变什么选择、关键未知是什么”，不为表格完整即编结论。
3. 按变化重要性、影响群体、选择敏感性、关键未知和取证成本选择下一条连续问题；优先理由写明，负责人按授权决定任务。
4. 深入产业或服务链时同步连接任务、新人入口及培养，避免只积累上游新闻后无限延期决策端。
5. 采用结果后更新本索引、受影响判断和下一优先项。任务合并只是采用记录，不是现实验证。

填充默认按已授权单元串行推进。框架设计通过不自动授权所有数据采集、隐私上传或无限工作。
