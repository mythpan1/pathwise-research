## 二、锁定信源口径与主笔深解要求

1. **国家政策信源与官文深解**：优先取**新华社、人民日报、中国政府网、《求是》杂志及国务院/部委/省厅官方原件**。研究主笔必须深解晦涩官文背后的治理痛点、真实资金落点与执行硬约束，严防把“设备资本深化补贴”误读为“应届生人力扩招”。
2. **产业结构信源**：优先取**政府监管与权威行业机构统计、龙头上市公司年报、招股书与行业标准**，严分“企业总营收/出海扩产”与“面向目标毕业队列（`graduation_cohort`）的国内应届用工净增减”。
3. **人口队列「官方基准锚 + 商业/基层旁证」双轨蒸馏**：强制同步核验母婴龙头财报销量、医院妇产科撤并缩床公告、民办园终止办学批复、中小学教师缩编与跨学段调配公告、医保与长护险基金决算及养老床位空置率，并校准江苏设区市与长三角核心城市分化。
4. **向下接口**：每篇定稿后向 [../l2-careers/README.md](../l2-careers/README.md) 移交锚定 `target_regions` 与 `graduation_cohort` 的张力信号包。
