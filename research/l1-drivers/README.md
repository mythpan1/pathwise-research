## 一、本层放什么（核心职责与地域/队列锚定）

本层承载上端三大连续宏观外驱的**交叉耦合信号卡**，负责查清未来 5–15 年驱动社会分工变化的底层结构力量，并向 [../l2-careers/README.md](../l2-careers/README.md) 交付显式锚定 **`target_regions`（目标就业地）** 与 **`graduation_cohort`（毕业队列）** 的《L1 宏观外驱张力信号卡》：
1. **人口结构变化（`L1-DEM-*`）**：双向穿透需求侧年龄队列（出生婴幼、学前至高教梯次达峰退潮、老龄慢病与失能照护）与供给侧人力资源队列（本硕毕业供给高位、在岗骨干退休节奏 vs 机构“退一不补/跨岗余缺调配”），并严格区分**全国总量方向**与**江苏/长三角局部城市的人口净流入、退休补员及地方财力分化**。
2. **国家政策工具（`L1-POL-*`）**：围绕《“十五五”规划纲要（2026—2030）》八大重合任务组合及部门/地方实施工具，穿透财政转移支付、专项债、地方化债约束、行业准入牌照与央国企/公立机构考核指标，严防把“政策推动设备资本深化”误读为“应届生人力扩招”。
3. **产业变迁周期（`L1-IND-*`）**：追踪技术工艺迭代、价值链利润转移、资本开支阶段（新建扩张期 vs 存量运维期）、甲乙方内外包拆分、产能落地的真实地理分布（本地总部研发 vs 外省基地/矿区驻场）及 AI/自动化对工种颗粒度的重构。

## 二、锁定信源口径与主笔深解要求

1. **国家政策信源与官文深解**：优先取**新华社、人民日报、中国政府网、《求是》杂志及国务院/部委/省厅官方原件**。研究主笔必须深解晦涩官文背后的治理痛点、潜台词、真实资金落点与执行硬约束，严禁照抄公文套话。
2. **产业结构信源**：优先取**政府监管与权威行业机构统计、龙头上市公司年报、招股书与行业标准**，严分“企业总营收/资本密集扩产”与“面向目标毕业队列的国内应届用工净增减”。
3. **人口队列「官方基准锚 + 商业/基层旁证」双轨蒸馏**：不孤立依赖单一宏观总数，强制同步核验“真金白银与基层行政动作”旁证——包括母婴/奶粉/纸尿裤龙头财报销量、各地医院妇产科撤并缩床公告、民办园终止办学批复、中小学教师招聘缩编与跨学段调配公告、医保与长护险基金决算及养老床位空置率，并核对江苏及重点目标城市的地方分化。
4. **防投毒入本前置**：所有原始材料须先落本地受控原料区完成硬主体过滤并贴血统头标后直传纯净 Gemini Notebook，回核原件后成稿。
