# 1.1.1 出生与婴幼队列坍缩及母婴妇产旁证（`L1-DEM-01.01` · 提纲占位卡）

> **当前状态**：`draft`（提纲已就位待填充正文；未回核一手原件前严禁填入未经核实的统计数值）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：2017 年以来全国与江苏出生人口台阶式下移在 2026–2035 年如何沿“产科—新生儿—托幼—儿童消费/伴侣动物替代”链条传导，微观商业财报与基层卫健/民政动作证实了多陡峭的收缩斜率？
- **不越界声明**：本篇仅锁定 0–6 岁婴幼队列与母婴医疗消费收缩信号；K12 中小学师资余缺归入 [1.1.2-学前至高中梯次达峰与教编跨学段调配](1.1.2-学前至高中梯次达峰与教编跨学段调配.md)，儿科/学前教育岗位入口与转岗分析归入 L2 对应岗位卡。

## 二、定制拆解提纲与待填核查清单

### 2.1 出生人口队列官方基准锚与育龄妇女分母锁定
- [ ] 核对国家统计局与《中国统计年鉴》2016–2026 年出生人口、一孩/二孩/多孩占比及 20–34 岁育龄妇女存量自然缩减基线，测算即使生育支持补贴加码情况下的 2027–2034 年出生规模上限区间。
- [ ] 对比江苏省统计公报与卫健委妇幼健康年报中的住院分娩活产数变化，识别龙年等短期生肖反弹后的结构回落特征。

### 2.2 母婴消费财报销量与渠道出清微观旁证蒸馏
- [ ] 提取婴配奶粉、纸尿裤及儿童乳品头部上市公司近三年年报中的销量吨数（剔除提价效应后的真实物理销量）、经销商数量净增减与产能利用率旁证。
- [ ] 对照宠物食品与伴侣动物医疗上市公司年报增速，评估“少子化家庭情感消费向伴侣动物转移”的真实支付替代弹性（传导至 `L2-CAR-06` 动医消费端）。

### 2.3 基层医院产儿科撤并缩床与普惠/民办托幼关停实证
- [ ] 梳理各地卫健委及公立/民营医院妇产科分娩业务关停、产科床位转医养结合或康复病区的公开通告，区分三甲危重孕产妇救治中心虹吸与县区二级医院产科塌陷。
- [ ] 核查教育部及地方教育局幼儿园在园幼儿数、民办园终止办学批复与公办园“幼随小走/托幼一体化”消化存量幼师编制的真实比例。

### 2.4 面向 `2031/2034` 毕业窗的下游外驱张力汇总
- [ ] 形成标准化张力信号表，明确对妇产儿科护理、学前教育、婴童食品品控三类下游链条在 `2027_in_2031_bachelor` 与 `2027_in_2034_master` 窗口的存量挤压等级。

## 三、待抓一手信源与受控数据核验靶点

1. **官方统计锚**：国家统计局年度国民经济和社会发展统计公报、《中国卫生健康统计年鉴》（住院分娩与产儿科床位表）、教育部全国教育事业发展统计公报（学前在园人数与专任教师数）。
2. **商业与基层旁证**：中国飞鹤、伊利股份、健合集团、豪悦护理、乖宝宠物、中宠股份等上市公司年报销量披露；市县行政审批局民办幼儿园注销公告。
