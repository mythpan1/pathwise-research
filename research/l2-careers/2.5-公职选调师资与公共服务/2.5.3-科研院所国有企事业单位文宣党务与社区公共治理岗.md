# 2.5.3 科研院所国有企事业单位文宣党务与社区公共治理岗（`L2-CAR-08.03` · 提纲占位卡）

> **当前状态**：`draft`（提纲已就位待填充正文；整合升级旧库 `8.2.4–8.2.5`、`8.2.8`、`8.4.3`）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：汉语言文学、马克思主义理论/思想政治教育、新闻传播学、社会学/社会工作、公共管理及心理学专业毕业生，在公务员考试之外，进入“江苏省属及各市事业单位统考”、“大型央国企党建纪检综合文秘岗”、“党报官媒融媒体中心”与“城乡社区专职工作者（社工岗）”的编制含金量与招录规模真相是什么？
- **不越界声明**：本篇覆盖非参公事业单位、央国企党群行政与社区社工心理服务岗位；科研院所理工核心研发岗已分别归入 `2.1` 与 `2.2`。

## 二、定制拆解提纲与待填核查清单

### 2.1 事业单位分类改革（公益一类全额拨款 vs 公益二类差额拨款 vs 转企改制）核查
- [ ] 抽取江苏省属及设区市事业单位统一公开招聘岗位表，核实管理岗（九级职员）、专技岗（图书档案、党校社科院、融媒体、文博场馆）对硕士学历、中共党员身份及文字材料写作（综合知识和能力素质）的真实竞争烈度。

### 2.2 大型央国企「党建组织 / 纪检巡察 / 办公室综合文秘」：文史哲马理论的核心体制出口
- [ ] 核查电网、烟草、能源、银行、铁路、中建等央国企校招中专门面向汉语言文学、马克思主义理论、法学、新闻学、行政管理招录的党群纪检综合岗：揭示其要求中共党员+名校硕士/优秀本科生且名额远少于主业理工岗但稳定性极高的特征。

### 2.3 官媒新闻采编缩招与企业新媒体公关在 AIGC 时代的去留
- [ ] 核对省级党报集团、广电总台年度校招名额与全媒体运营转型现况，对比市场化新媒体运营岗的低门槛高替代风险。

### 2.4 城市社区工作者（社工员额）与社会心理服务岗位的薪酬边界校准
- [ ] 客观区分“苏南/南京部分街道带五险一金与规范晋升阶梯的社区专职社工（社会工作师持证补贴）”与“公益机构低薪项目制社工”，以及应用心理学在无精神科医师资格（不可开处方）下的真实就业半径。

## 三、待抓一手信源与受控数据核验靶点

1. **官方招录信源**：江苏省人力资源和社会保障厅年度省属事业单位统一公开招聘人员公告及岗位表、中央企业校园招聘党群纪检岗位公示、南京/苏州社区专职工作者公开招聘简章。
2. **映射字典靶点**：对接 `D5` 中人文社科专业在体制内文字党务岗与基层社工岗的政治面貌（中共党员）前置条件标注。
