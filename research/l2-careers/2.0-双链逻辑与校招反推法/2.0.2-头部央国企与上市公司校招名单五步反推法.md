# 2.0.2 头部央国企与上市公司校招名单五步反推法（`L2-CAR-03.01` · 提纲占位卡）

> **当前状态**：`draft`（常青方法论提纲卡；吸收升级第一代 `5.9.1–5.9.5` 与 `8.7.2`，严守一手公示分母与来源去重）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：如何绕开自媒体软文和模糊的高校总就业率，直接利用国家电网、中烟、军工十大集团、三大运营商、铁路局、选调机关及头部民企每年依法公开的《校园招聘简章》与《拟录用人员公示名单》，反向锁定哪些大学和专业代码握有真实的“Target School 入场券”？
- **不越界声明**：本篇规范“从雇主拟录用端倒推院校与专业”的五步取证协议；严禁使用二手商业薪资推断值伪装原始统计分位数（纠偏旧库 `5.2.19`）。

## 二、定制拆解提纲与待填核查清单

### 2.1 一手校招证据源黄金四件套与来源家族去重规则
- [ ] 建立标准抓取清单：① 央国企招聘平台（如国家电网人资招聘平台、国聘网、各省国资委联招）拟录用公示原表（含姓名脱敏后的毕业院校、学历层次、录用单位地市）；② 企业进校线下宣讲会行程单（Target School 直接证据）；③ 公务员/选调生年度招考简章职位表与拟录用公示；④ 上市公司年报员工学历与薪酬总额附注。
- [ ] 锁死去重铁律：多家门户网站或公众号转载同一批拟录用统计图，仅计为 1 个同源家族，必须核回官方网站原始公示批次。

### 2.2 五步反推操作流：目标雇主 → 用人子单位地域 → 学历底线 → 精确专业代码 → 高校梯度
- [ ] 拆解“同一央企内部省公司/市局/县公司/偏远电厂工程局”的天壤之别：验证同一张企业招牌下，名校硕士进南京/苏州省市研发调度中心与普通本科进偏远工区驻场的真实分层。

### 2.3 原部属行业特色院校“历史血统护城河”识别准则
- [ ] 建立原电力部、兵工七子、国防七子、邮电部、铁道部、交通部、水利部、审计署、海关总署直属或共建高校在对应行业系统校招中的“提前批免笔试/降档准入”核验清单。

### 2.4 伪热门专业证伪过滤器（高高考分数线 × 低头部雇主点名率）
- [ ] 设定交叉证伪测试：凡高考录取位次高企或概念响亮，但在央国企职位表与龙头大厂核心研发岗 JD 中极少被单独点名（仅能混报不限专业岗）的专业，强制标记“名不副实预警”。

## 三、待抓一手信源与受控数据核验靶点

1. **官方校招公示平台**：国家电网有限公司人力资源招聘平台、中国烟草人才招聘平台、三大运营商校园招聘官网、国家公务员局专题网站、各省组织部选调生公告。
2. **下游衔接靶点**：直接为 `2.1–2.5` 岗位卡及 `3.1` 江苏可及院校实得比较提供 `1B` 雇主白名单证据。
