# 2.0.1 专业与职业三层对口双链逻辑及跨专业迁移实况（`L2-CAR-01.01` · 提纲占位卡）

> **当前状态**：`draft`（常青方法论提纲卡；吸收升级第一代 `8.0.1–8.0.3` 与 `8.6.1`）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：为什么社会上同时流行“学什么专业毕业根本不干本行”与“选错专业考公进医院直接报不了名”两种看似矛盾的说法？本科专业与真实职业岗位之间究竟遵循哪三层刚性不等的对口映射与不可逆单向迁移铁律？
- **不越界声明**：本篇界定全专业门类到岗位族的三层对口拓扑结构（对接 [../../../data/README.md](../../../data/README.md) `D5` 字典）；各行业具体校招门槛分别见 `2.1–2.5`。

## 二、定制拆解提纲与待填核查清单

### 2.1 三层对口光谱拆解：法定牌照锁死层 vs 学科硬课门槛层 vs 通用能力开放层
- [ ] **第一层（严格法定/目录锁死）**：梳理执业医师（限五年制以上医学学位）、法律职业资格（新办法限全日制法本或非法本法硕/三年法律工作经验）、公安联考、海关检疫及国网电工类一批等**零跨界容忍**清单。
- [ ] **第二层（广义数理工程同源可迁移）**：梳理数学/物理/电子/自动化/计算机/测控之间凭核心硬课与项目经历在考研及市场化校招中的相通边界与补课摩擦成本。
- [ ] **第三层（无专业限制通用池）**：解析企业销售运营、互联网产品、银行柜面营销、公考“三不限”岗位为何因零准入壁垒而承受全学科毕业生洪峰的无差别挤压。

### 2.2 单向不可逆跨界定律（高壁垒向下兼容 vs 低壁垒逆向禁入）
- [ ] 绘制跨学科可逆/不可逆有向矩阵：验证“硬核工科/数理 → 量化金融/专利法务/技术商务/体制综合岗”顺向兼容的现实机制，以及“纯文商管理 → 临床/电气/硬件研发”逆向锁死的制度根源。

### 2.3 毕业五年内跨专业就业真实流向与薪酬折价/溢价条件
- [ ] 对照高校就业质量报告与教育统计调查，区分“主动跨界升级（如机械+嵌入式进机器人、化工+法硕进知产）”与“被迫降维转行（因本专业无岗位退入无门槛销售客服）”的本质分野。

### 2.4 对接 `D5` 多对多映射字典的标注规范
- [ ] 定义每条 `primary_routes / backup_routes` 必填的 `degree_threshold` 与 `license_ids` 标准枚举口径。
