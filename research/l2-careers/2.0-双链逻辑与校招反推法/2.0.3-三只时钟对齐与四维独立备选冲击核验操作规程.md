# 2.0.3 三只时钟对齐与四维独立备选冲击核验操作规程（`L2-CAR-02.01` · 提纲占位卡）

> **当前状态**：`draft`（常青方法论提纲卡；以串联硬关卡与四维独立性核验全面替代旧库 `8.7.1` 主观 `0–100` AHP 加权总分，对接 `D6` 接口）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：如何确保每一份职业与志愿规划既不犯“拿 2026 年眼前热点当 2031/2034 年毕业景气”的时钟错位病，又不犯“表面选了 B 方案保底，实则与 A 方案捆在同一个专业组或共卡同一场考研/法考而双双暴雷”的假备选病？
- **不越界声明**：本篇锁定 `L2` 与 `L4` 强制执行的时钟对齐与四维主备独立性冲击核验规程（对齐 [../../../scripts/README.md](../../../scripts/README.md) `D6`）；不涉及具体考生个人偏好录入。

## 二、定制拆解提纲与待填核查清单

### 2.1 三只独立时钟（政策期 / 毕业窗 / 复利窗）强制换算公式与反例警示
- [ ] 建立按入学年份 `T` 动态展开的三钟对照表：政策与基建时钟（`2026–2030`） vs 毕业入职时钟（四年本 `T+4`、五年本 `T+5`、本硕 `T+7`、临床规培 `T+8~10`） vs 35 岁能力复利时钟（`T+10~12`）。
- [ ] 检验“读研多花 3 年的净效应”：区分“跨过刚性准入门槛（值得读）”与“无新硬壁垒却一头撞进更深峰后存量挤压（本硕倒挂风险）”。

### 2.2 付款人 → 承接组织 → 应届转化 → 新人受监督带教四问串联漏斗
- [ ] 明确五类底层付款池枚举（一般公共财政、医保/长护基金、垄断央国企运维刚需、竞争性制造业资本开支/研发、居民自付消费），强制排查是否存在“企业只招 3 年经验熟手/外包、零经验应届生无带教复核”的断桥。

### 2.3 备选路径「四维独立冲击核验」硬门禁（对接 `D6` 防假独立）
- [ ] 逐维定义主路径与 `Rank 3` 备选路径的共损测试：① **付款主体隔离**（防甲乙方同吃地方城投或同吃房地产链）；② **江苏同组调剂隔离**（若两专业在苏混编于同一院校专业组且未书面隔离调剂，严禁互作投档保底）；③ **学历/执照准入隔离**（防主备同时依赖统考读硕或同考一张高难法考/执业医证）；④ **地域/组织单点隔离**。
- [ ] 固化未知阻断铁律：凡主备任一路径准入门槛或当年章程调剂规则未核清，一律返回 `unknown_blocked`，严禁放行冒充 `pass`。

### 2.4 确定性梯度承压阀（防防御性推演无限套娃）
- [ ] 规定完成上述漏斗与四维核验后，必须在明示置信度与触发换序信号的前提下输出清晰的默认优劣排序，严禁停留在无主次的 `if-else` 平铺。
