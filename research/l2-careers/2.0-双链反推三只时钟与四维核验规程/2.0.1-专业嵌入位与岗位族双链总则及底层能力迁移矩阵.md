# 2.0.1 专业嵌入位与岗位族双链总则及底层能力迁移矩阵（`L2-CAR-01.01` · 提纲占位卡）

## 一、本篇问题定位与不越界声明

- **核心回答问题**：如何彻底破除“本科专业名称与岗位名称字面一一对口”的陈旧迷思，按「本科主干学科 → 三层制造嵌入位（硬嵌硬 / 软嵌硬·理嵌工 / 服嵌造）→ 跨行业岗位族」建立多对多底层能力迁移矩阵？
- **不越界声明**：本篇为 `L2` 常青总则卡（`stability: evergreen`），定义岗位族多对多归口与横向迁移规律（严禁按甲方行业重复拆平行野卡）；央国企与筑峰强链三段校招核验归入 `2.0.2`，三只时钟与 D6 备选核验归入 `2.0.3`。

## 二、定制拆解提纲与待填核查清单

### 2.1 破除字面对口迷思：从终端品牌兴衰到底层共性制造能力复用
- [ ] 拆解同一底层工程技能（如功率电子变流、高精度伺服控制、多物理场热流仿真、多级 BOM 成本控制）如何在半导体设备、智能汽车、工业机器人、新型电力、航空航天与高技术船舶间低损平迁（`[分析推断]`）。

### 2.2 「专业簇 ↔ 三层嵌入位 ↔ 岗位族」多对多映射规则（对接 `D5` 字典）
- [ ] 对齐 [data/README.md](../../../data/README.md) `D5` 公共字典结构，规范同一国标专业挂载多条 `primary_routes[]` 与 `backup_routes[]` 时在岗位族、付款主体、地域与学历/执照门槛上的逐路径分列标准。

### 2.3 跨层迁移硬壁垒清单：哪些方向可凭作品集/辅修平迁，哪些受法定目录硬锁死？
- [ ] 明确临床执业医师、五年制执业兽医、国家电网电工类统考一批、法考应届资格等不可跨界硬门槛，与工业软件、SPC 良率、制造业财、涉外商务等可跨专业切入通道的边界。
