## 一、本层放什么（岗位族多对多转换职责）

本层是连接上端宏观外驱（[../l1-drivers/README.md](../l1-drivers/README.md)）与下端高校专业培养（[../l3-pathways/README.md](../l3-pathways/README.md)）的**多对多岗位族转换器**：
1. **职业岗位族（Role Family）多对多归口**：`L2-CAR-01~09` 按**岗位职能族**（而非单一产业）归口，与上游 `L1-IND-01~09` 及下游 `L3-PTH-01~08` 均为**多对多映射关系**。跨行业通用职能（如软件开发交付、自动化联调、财会审计、法务合规）统一归入所属岗位族主槽内，横向对比不同承接行业（如技术原厂 vs 制造甲方 vs 医疗/公共机构）的付款主体、工作地域、招聘学历门槛与应届转化率。
2. **三只独立时钟与 `target_regions × graduation_cohort` 强制对齐**：将 `2026–2030` 政策建设期、按考生真实入学年 `T` 计算的毕业入职窗（`T+4` 本科 / `T+5` 五年制 / `T+7` 硕士 / `T+8~10` 长周期）及 `T+10` 复利窗分开校准，并明确锁定**谁在何地（江苏本地 / 长三角 / 全国流动 / 异地驻场）、面向哪一届普通生放开校招**。
3. **付款人 → 承接组织 → 应届名额转化与带教漏斗**：穿透持续买单主体、签约承接组织、资本深化/存量内部调配/外包 vs 外部正式校招转化比例，以及是否允许零经验应届生进入受监督实操并获熟手复核。
4. **「四维独立备选冲击核验」**：克服“仅付款人不同仍可能同组滑档或考研双双失利”的假独立盲区，强制从**付款主体 × 江苏同组调剂隔离 × 学历/执照门槛 × 地域/承接组织单点**四个维度核验主备独立性并如实披露共享故障点。

## 二、锁定信源口径与确定性梯度规则

1. **锁定信源**：优先核验央国企/国家电网/大型三甲医院及代表性头部企业官方校招简章与拟录用公示（含工作地点与录用院校学历分布）、上市公司年报员工结构、政府部门及医保基金预决算公开表。
2. **确定性梯度承压阀（防悬空停机）**：中远期（4–15 年）分析不强求预测未来某年精确编制绝对数，但严禁把“待填字段”冒充已闭合证据；完成时钟地域对齐、应届转化证伪与四维备选核验后，即收口输出岗位族默认优劣序与准入硬门槛移交 `L3`。

## 三、严禁放入本层的内容

- 严禁将同一跨行业通用岗位按行业复制拆出多张相互矛盾的平行野卡；
- 严禁把“在江苏同一院校专业组捆绑暴露”或“共享单一刚性考研/高难执照门槛”的路径宣称为无条件独立保底；
- 严禁出现真实个人姓名、本机绝对路径、拍脑袋主观概率打分或未核回硬主体的传闻薪资。
