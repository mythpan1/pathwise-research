# 2.3.3 医学影像检验康复护理与疾控公卫支付上限分析（`L2-CAR-07.03` · 提纲占位卡）

> **当前状态**：`draft`（提纲已就位待填充正文；吸收 v2 南京医科组康复/影技/医检深度机制穿透并补齐收敛排序）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：无需经历 8–10 年临床手术苦熬的医技、护理与公卫序列——医学影像技术、医学检验技术、康复治疗学、护理学与预防医学，在 DRG 控费、检验集采外包与公立医院定编收紧下，哪一个本科就业去向率最刚性，哪一个正陷入“高扩招、低岗位放量”挤压？
- **不越界声明**：本篇横向比较医技、康复、护理与公卫五条医疗非手术路径的岗位规格；具体高校培养方案与组内混编排雷归入 `3.1.9–3.1.10`。

## 二、定制拆解提纲与待填核查清单

### 2.1 医学检验技术（`101001`）与医学影像技术（`101003`）：公立技师满编与自动化挤压评估
- [ ] 核查省市级医院检验科（经历前期扩编饱和+全自动生化流水线+省域检查结果互认+第三方金域/迪安集采降本）当前公开招聘名额骤减实况。
- [ ] 对比医学影像技师（CT/MRI/放疗物理师操作岗）在二级以上医院及放疗中心的设备配比定编与辐射防护津贴休假制度。

### 2.2 康复治疗学（`101005`）：老龄生理需求巨大 vs 医保单次支付上限与高阶带教瓶颈
- [ ] 穿透“医院康复科受医保住院天数与按项目收费上限约束，基层社区缺高水平运动/神经康复带教治疗师，商业运动康复自付客群集中在少数一线商圈”的三重现实张力。

### 2.3 护理学（`101101K`）：全医疗谱系唯一本科直入三甲高确定性通道 vs 高强度夜班流失率
- [ ] 客观呈现双一流/医科大学护理学本科生（尤其男护在急诊/ICU/手术室）进省会及苏南三甲医院的极高一次录用率，并如实对齐三班倒夜班体力消耗、护患沟通压力及未来转向临床研究协调员（CRC）/专科护士的路径。

### 2.4 预防医学（`100401K`，五年制医学学位）：疾控中心/卫健委/海关公考窄门与公卫硕士门槛
- [ ] 核查省市县三级疾控中心（CDC）、卫生监督所与海关卫生检疫岗位编制回归常态后的真实年度招录规模与硕士学历倾斜。

## 三、待抓一手信源与受控数据核验靶点

1. **一手招聘原件**：江苏省及南京/苏州/南通卫健委事业单位公开招聘岗位表（分列护理、影像技师、检验技师、康复治疗师、公卫医师招聘人数与学历要求）、海关卫生检疫国考职位表。
2. **契约核验靶点**：核对上述专业在江苏医科大学“医学技术专业组”内混编时的 `water_level` 水位暴露风险。
