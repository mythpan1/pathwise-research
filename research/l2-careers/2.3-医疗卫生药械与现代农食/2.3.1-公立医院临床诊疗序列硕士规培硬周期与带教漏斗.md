# 2.3.1 公立医院临床诊疗序列硕士规培硬周期与带教漏斗（`L2-CAR-07.01` · 提纲占位卡）

> **当前状态**：`draft`（提纲已就位待填充正文）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：2027 级临床医学/中医学新生走完至少 8 年（5 年本科 + 3 年专硕四证合一规培，至 `2035` 年）乃至 11 年博士周期入职时，江苏省市三甲医院、苏南百强县三甲与苏北二级/基层医院的招聘学历硬底线、编制备案制待遇及科室冷热格局会发生怎样的结构演变？
- **不越界声明**：本篇锁定临床与中医执业医师公立医院主航道；口腔/视光商业专科归入 [2.3.2-口腔眼视光消费医疗与医疗器械临床技术支持岗](2.3.2-口腔眼视光消费医疗与医疗器械临床技术支持岗.md)，省内医学院校学制与直属附院比较归入 `3.1.9`。

## 二、定制拆解提纲与待填核查清单

### 2.1 江苏省各级公立医院公开招聘学历与“两个同等对待”实效核查
- [ ] 抽取江苏省卫健委直属医院（省人民医院、鼓楼医院、中大医院、苏大附一、省中医院）、设区市三甲及昆山/江阴/常熟/张家港县市医院近两年高层次与公开招聘岗位表：核实主城区三甲临床岗是否已全面下沉至博士/八年制（仅急诊、儿科、病理、全科、康复偶留硕士口），县市医院对临床专硕的吸纳容量。
- [ ] 检验本科毕业未考上专硕、直接去社会化规培（“两个同等对待”政策）在实际医院录用与晋升主治医师中的真实认可度。

### 2.2 科室结构性分化：老龄慢病肿瘤介入刚需 vs 产科儿科缩床转岗
- [ ] 结合 `1.1.1` 与 `1.1.4` 人口队列，对比心内、神内、肿瘤、骨科、眼科、重症、麻醉、老年医学与产科、普通儿科在 `2035` 毕业窗的病源支撑力和夜班医疗纠纷烈度。

### 2.3 长周期培养财务缓冲硬门槛（26–29 岁前低薪规培期）
- [ ] 核算五年制本科+三年专硕规培（或再读三年博士）期间的生活补助与学费账，向 `L4` 传递“家庭能否承受孩子 27–29 岁才实现经济独立”的刚性前置筛选条件。

### 2.4 中医学/中西医临床医学的执业范围与中医院/综合医院招聘窄门核验
- [ ] 厘清中医类别执业医师在西医综合医院科室受限边界，以及县市级中医院与基层社区卫生服务中心的编制敞口。

## 三、待抓一手信源与受控数据核验靶点

1. **官方招聘原件**：江苏省人力资源和社会保障厅省属事业单位（卫健系统）统一公开招聘岗位表及拟聘用公示、南京/苏州/无锡/徐州卫健委直属医院公开招聘公告。
2. **契约核验靶点**：对接 `D5/D6` 中 `LIC_PHYSICIAN` 执业医师资格证与 `master_mandatory` 学历门槛；医院公开招聘及规培基地体检要求按年度、医院与科室岗位记入 `D5` 职业风险提示，高校医学类专业限报（`D2-B.physical_limit_codes`）单独引用当年招生体检指导意见与高校招生章程核定，两层依据分列记录不混同。
