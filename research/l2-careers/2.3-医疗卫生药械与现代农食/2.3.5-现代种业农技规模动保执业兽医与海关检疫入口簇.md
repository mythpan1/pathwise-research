# 2.3.5 现代种业农技规模动保执业兽医与海关检疫入口簇（`L2-CAR-06.01` · 提纲占位卡）

> **当前状态**：`draft`（提纲已就位待填充正文）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：为什么在综合 985/211 录取分偏低的动物医学、动植物检疫、植物保护与种子科学专业，反而拥有“海关/农业局公考低报录比护城河 + 执业兽医牌照垄断宠物医疗 + 涉农双一流高保研率”三重结构优势？其背后对应的驻场或临床脏累环境门槛是什么？
- **不越界声明**：本篇聚焦动医、植保、种业与动植物检疫岗位；食品科学与粮油检测归入 [2.3.6-食品工业品控研发大宗粮油供应链与检测认证岗](2.3.6-食品工业品控研发大宗粮油供应链与检测认证岗.md)。

## 二、定制拆解提纲与待填核查清单

### 2.1 海关总署（南京海关/上海海关等）动植物检疫与基层农业农村系统公考窄门核验
- [ ] 提取近三年国家公务员考试职位表中南京海关、上海海关、宁波海关等口岸海关限定“动物医学、动植物检疫、植物保护”专业的招录人数、进面分数线与报录比，对比通用文商科岗位验证其显著的体制内降维竞争优势。

### 2.2 伴侣动物诊疗（城市宠物医院）执业兽医成长路径与收入分化
- [ ] 核查全国执业兽医资格考试通过率与法定限考专业边界（仅兽医相关专业可考），还原宠物医院从医助（1–2 年低薪熬夜练手）→ 全科主治兽医 → 骨科/眼科/异宠专科院长助理的真实薪资阶梯与伤情卫生耐受要求。

### 2.3 大型农牧与动保疫苗药企（牧原/温氏/海大/中牧/瑞普）校招规格
- [ ] 区分① **养殖场驻场兽医/场长管培**（本科高起薪包吃住，但需接受数周封闭生物安全隔离）与② **动保疫苗研发/大客户技术服务工程师**（硕士优先、省际技术巡回）的现实权衡。

### 2.4 种业央国企（先正达中国/隆平高科/苏垦农发）育种研发与农服植保通道
- [ ] 核查江苏省农垦集团（苏垦农发）等省属大型现代农业国企对农学、植保、种科应届生的稳定招录池与工作驻地。
