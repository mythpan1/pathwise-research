# 2.2.1 智能制造机械研发新能源汽车与机器人具身工程岗（`L2-CAR-02.02` · 提纲占位卡）

## 一、本篇问题定位与不越界声明

- **核心回答问题**：机械工程、机械电子、能源动力（热管理/发动机）与机器人工程毕业生，在长三角密集的新能源车企/Tier-1 零部件、半导体/锂电高端装备、国防军工机械院所及具身机器人公司中，正向结构/电驱/热管理/运控研发岗与工厂制造工艺（ME/IE/QE）岗的本硕分界线在哪里？
- **不越界声明**：本篇聚焦机械本体研发、热管理电驱与工厂制造工程岗；PLC 现场联调出差与轨交海事民航专有维保归入 [2.2.2-工业自动化现场联调测控验证与低空交通专有维保岗](2.2.2-工业自动化现场联调测控验证与低空交通专有维保岗.md)。

## 二、定制拆解提纲与待填核查清单

### 2.1 正向研发层（结构仿真 CAE / 三电热管理 / 电机控制 / 机器人运控）硕士门槛核查
- [ ] 核对车企研发中心（上海、苏州、常州、南京、合肥）、航空航天与兵工机械院所、工业及人形机器人本体厂商研发岗校招 JD，明确有限元仿真、流体传热、电机电控与运动控制算法对双一流工科硕士的刚性偏好。

### 2.2 制造工艺与质量层（ME 制造工程 / PE 工艺 / SQE 供应商质量）的本科海量吸纳池
- [ ] 客观还原苏锡常宁外企（博世、西门子、博格华纳等）与本土制造龙头面向普通公办本科机械生的最大就业基本盘：起薪稳健、越老越熟知加工公差与供应链，但需驻厂进车间且起薪低于纯软件。

### 2.3 船舶海工与航空发动机长周期景气下的结构/动力研发增量
- [ ] 结合江苏全国第一造船大省（南通、泰州靖江、扬州、镇江）与商发/航发产业链，核查船体结构、轮机动力与特种焊接工艺岗位的校招缺口与地域驻点。

### 2.4 主备路径「四维独立冲击核验」
- [ ] 检验“冲车企/机器人正向研发硕”与“长三角高端装备/外企工艺质量本科直就”或“军工机械国企”在付款周期与学历门槛上的梯度容错，揭示机械类专业越老越吃香的物理工程复利特征。
