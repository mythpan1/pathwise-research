# 4.3.5 历史类与物理兼报带收口-考公法务财会出海商务与峰后师范重排（`L4-DEC-05.01` · 提纲占位卡）

> **当前状态**：`draft`（`L4-DEC-05` 主干收口卡；全面落实 2029 高中生源达峰后的师范赛道重估与文商法主备四维独立配对）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：面向江苏**历史类全分段考生**以及**物理类非物化选科/倾向文商政法考公的兼报考生**，当传统最稳的“师范当老师”在 `2031/2034` 毕业窗正面撞上初高中达峰后缩编与调配挤压时，**法学、会计审计税务、汉语言文学、经济金融统计、公安海关提前批与制造业跨境出海商务/小语种复合**六条主干路径该如何重新排出 `Rank 1–3` 默认优先级？
- **不越界声明**：本篇统一收口历史类全段与物理文商兼报带决策；提前批公费师范与警校锁死代价细则联动 [4.3.6-高约束特殊通道vs普通批常规自由路径锁死成本与止损收口](4.3.6-高约束特殊通道vs普通批常规自由路径锁死成本与止损收口.md)。

## 二、定制拆解提纲与待填核查清单

### 2.1 默认基准前提包与文商兼报带三大排雷铁律
- [ ] 明示默认前提：江苏历史类（重点区分再选含政治 vs 不含政治）及物理非化兼报生源、目标在江苏/长三角实现“体制公考选调有大户代码兜底 + 市场化有专业门槛手艺”双栖安全。
- [ ] **三大前置排雷**：① 拒报双非院校无硬代码的泛工商管理/市场营销/公共事业管理/旅游管理；② 严禁把“纯教育学/学前教育”等同于汉语言/数学主科师范；③ 非顶尖名校慎报纯宽泛金融学。

### 2.2 峰后重排后的 `Rank 1 → Rank 2 → Rank 3` 基准主序（体制与市场两栖优先）
- [ ] **`Rank 1`（硬牌照/硬代码两栖双核主推）**：**法学（`030101K` 纯法学组，五院四系/985/苏大南师南审等，通吃公检法司公考第一大户 + 法考执业壁垒）** 与 **会计学/审计学/财务管理/税收学（`120203K/120207/020202`，两财一贸/南审/南财及强 211，通吃国考第一招录大户税务审计 + 全行业企业业财内控）**。
- [ ] **`Rank 2`（体制文字王牌与高门槛选调平台）**：**汉语言文学（`050101`，含汉语言师范——注意其核心底盘是考公文秘党务大户，招教退居第二期权！）**，或高分段 **985 名校文史哲社政平台（主打江苏名校优生定选 + 30% 保研率）**；再选政治合格者优先扫描提前批**公安院校/上海海关学院**高确定性入编口。
- [ ] **`Rank 3`（待经四维逐对冲击核验的异构备选候选）**：将**长三角制造业跨境出海商务 / 国际物流供应链 / “外语+法商工科”双学士项目**列为市场化异构候选，针对实际选定的 `Rank 1` 具体路径（法学或财会审计税务）逐对核验全部四维（制造业出口现金流 vs 国内地方财政/律所付款池、是否同专业组混编调剂、是否共卡单一法考 `LIC_LEGAL_BAR` 或公考门槛、目标城市与承接企业单点）；任一维缺少当年招生章程或校招实证时必须保留未知（`unknown_blocked`），严禁未核先判独立保底。

### 2.3 一级换序触发信号（何时师范可重回首选？物理非化生如何加挂量化优势？）
- [ ] ① 若考生够得着部属六师/南师苏大顶尖主科且家庭接受县市中学或备案制，或符合本县刚需且愿签乡村教师定向 → 主科师范可升序；② 若为物理+非化考生 → 优先用**信息管理、工程造价、金融工程、经济统计**替代纯文科专业，保留数理降维优势。

### 2.4 历史与文商兼报带招办核实总单
- [ ] 重点核查法学组是否混入社会工作/公管、工商管理大类分流进会计审计的名额上限、以及外语专业是否具备入学即定的双学士学位资格。
