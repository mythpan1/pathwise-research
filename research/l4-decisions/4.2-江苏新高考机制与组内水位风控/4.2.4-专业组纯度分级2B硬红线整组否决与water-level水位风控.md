# 4.2.4 专业组纯度分级2B硬红线整组否决与water-level水位风控（`L4-DEC-04.01` · 提纲占位卡）

## 一、本篇问题定位与不越界声明

- **核心回答问题**：如何按目标年 `D2-D` 章程三类调剂模式分别裁定实际暴露集 `S`（全组调剂 `S = G`、已核子集调剂 `S = T ∪ (A \ E)`、已核书面不调剂 `S = T`）并区分主动目标集 `T` 与暴露集 `S`，分两步执行「`2B` 阶段一硬红线否决」与「基于区间锁定证据的 `water_level` 五态水位分级」，彻底杜绝单凭最低分伪推分位与混编踩雷？
- **不越界声明**：本篇为江苏专业组纯度风控核心常青卡（`stability: evergreen`，零主观加减分打分表），100% 映射 [scripts/README.md](../../../scripts/README.md) §2.2 两阶段判定状态机。

## 二、定制拆解提纲与待填核查清单

### 2.1 当年章程 `D2-D` 实际录取暴露集 `S` 裁定与阶段一 `2B` 硬红线整组否决（`gate1_status = VETOED`）
- [ ] 严格按 `D2-D` 调剂模式分支裁定暴露集 `S`：全组调剂默认 `S = G`；**仅「已核子集调剂（`subset_isolated_verified`）」适用 `S = T ∪ (A \ E)`**（书面排除项 `E` 仅从被动调剂集 `A` 剔除，绝不从主动目标集 `T` 剔除）；满足书面不调剂承诺条件时 `S = T`；若 `group_target_valid == false` 或 `D2-D` 未核全则回退 `S = G` 并阻断保底。阶段一将**逐成员硬红线**与**学历深造条件**单列：① `S` 内任一可达成员（含大类招生按该校当年该组可分流专业集核查；集合不完整且不能排除红线时禁入保底，禁拿跨校通用别名替代）命中选科、`D2-B` 体检、超学费、单科语种或绝对排斥专业/7 类场景红线，即整组否决；② 学历条件（`bachelor_direct_only`）严格区分 `T` 与 `S`——**仅当主动目标集 `T` 中全部目标专业的全部可达主路径均刚性要求深造/规培时才触发 `VETO_DEGREE_MISMATCH` 整组否决**（若 `T` 内存在具备已核 `bachelor_direct` 主路径的目标专业则不否决全组，但 `S` 仍含刚性深造或未知门槛成员时拦出 `safety` 保底池）。

### 2.2 阶段二非红线组内 `water_level` 五态水位区间核定（`top / mid / low / bottom / unknown`）与伪分位硬阻断
- [ ] **严禁仅凭每专业最低录取位次（`major_min_rank`）与录取人数（`admitted_count`）伪推组内分位或准入保底**（相同最低位次与人数可对应 `top` 或 `bottom` 相反分布）：唯有具备 `S` 内**同口径组内录取位次分布**，或具备上下界证据使排在考生前面人数的占比区间 `[P_min, P_max]` 唯一落入同一分位档（`top <=20% / mid (20%,50%] / low (50%,80%] / bottom >80%`）时，才输出该分位档；**否则（含仅有最低位次与人数致区间跨档、缺核心字段、大类分流集不完整或 `D2-D` 未核清）一律沿用 `water_level = "unknown"` 且 `safety_pool_blocked = true`**（若单列“按人数加权的专业最低门槛过线指标”，仅作门槛参考，绝不替代真实分位或直录概率）。

### 2.3 客观混编标签（`mixed_structure_tags[]`）与“宁降半档锁 `top` 水位纯净组，绝不 `low/bottom` 赌混编组”准则
- [ ] 用 `cross_discipline_mix / sino_foreign_mix / high_tuition_mix / transfer_restricted_present` 客观标签替代拍脑袋扣分，明确含 `soft_dislike` 且处于 `low/bottom` 水位的专业组强制拦出保底池。
