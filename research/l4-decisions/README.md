## 一、本层放什么（`3B` 公私双模收口与情景锚定）

本层严格执行**「公共研究底座（入公开库） + 个案志愿闭环（留本地受控区）」双模解耦（`3B`）**：

1. **本目录存放的内容（`L4A` 情景锚定公共决策底座）**：
   - 围绕江苏普通批可及生源的 **6 大典型取舍两难**（`L4-DEC-01~06`），综合上游 `L1–L3` 已核卡片（参见 [../l3-pathways/README.md](../l3-pathways/README.md) 与 [../../index/manifest.json](../../index/manifest.json)）跨路径收口；
   - **强制声明「默认基准前提包」**：公开库的 `Rank 1–3` 不是脱离家庭条件的绝对真理，每张卡片必须在首节显式锚定其默认前提（如默认选科、省外同档院校接受度、常规公办本硕成本支持度、目标 `target_regions` 与 `graduation_cohort`），在此前提下给出 **`Rank 1 默认主推 → Rank 2 同簇稳健替代 → Rank 3 经四维冲击核验的独立备选`**、一级换序触发信号及填报前招办核实总单。
2. **本地受控区联动机制（`L4B` 个案志愿与职业闭环，不入本目录）**：
   - 服务具体考生时，在本地受控区读取实填四维个体/家庭约束卡，对照公开卡基准前提触发换序，并调用 [../../data/README.md](../../data/README.md) 与 [../../scripts/README.md](../../scripts/README.md) 定义的对应年份招生底表（含 `D2-D` 当年章程与实际调剂覆盖/隔离表）、分段超额漂移及 **`2B` 风控引擎**（硬红线整组否决 + 非红线组内 `water_level` 水位分级；凡任一可调剂成员缺失历年专业最低位次/录取人数、红线字段未知或当年调剂规则状态为 `unknown`，一律判定水位未知并硬拦截进入保底池），输出终端志愿方案与 4–7 年路线图。

## 二、收口质量硬边界

1. **基准前提透明 + 拒绝防御性平铺**：必须明示默认基准前提并给出清晰的 `Rank 1–3` 基准主序，严禁既不写前提伪装普适、又用五路并列逃避排序。
2. **备选路径「四维独立冲击核验」**：`Rank 3` 必须同时接受**付款主体、江苏同组调剂隔离、学历/执照门槛、地域/承接组织单点**四类假设冲击检验，显式披露仍共享的弱点，**严禁把同专业组捆绑暴露或共享单一刚性考研门槛的路径充当独立保底**。
3. **零拍脑袋权重与零 MBTI**：严禁使用无实证主观加权总分或通俗心理测试标签。
