# 4.1.3 家庭本硕学费上限教育回本周期与3至5年低薪期缓冲测算（`L4-DEC-06.02` · 提纲占位卡）

> **当前状态**：`draft`（常青方法卡；重构升级第一代 `10.2.1–10.2.2` 教育投资回报与家庭财务风险承受力框架）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：为什么两个考分完全相同的学生，一个适合报“中外合作计算机 + 港英一年硕”或“五年制临床 + 专硕博士十年慢热路”，另一个则必须果断锁定“公办低学费电气/自动化/警校/公费定向，22 岁本科毕业即拿稳健正现金流”？如何客观盘点家庭四档财务缓冲底线以防止掏空养老金？
- **不越界声明**：本篇提供去隐私化的家庭教育财务压力测试模型（对接 `D6` `dim2_financial_horizon`）；具体实填金额仅在本地受控区运行。

## 二、定制拆解提纲与待填核查清单

### 2.1 四档家庭教育总预算包（4–10 年全周期口径，拒绝只看大一首年学费！）
- [ ] **档位 I（零/低成本急需自立型）**：公费师范/军警校/公办普通专业（年学费 `5000–6800 元` + 国家助学政策），要求 `T+4` 本科毕业即独立养活自己并反哺家庭——刚性剪除中外合作、纯基础理化生及长周期临床法学。
- [ ] **档位 II（常规公办本硕支持型）**：支持公办本科 4–5 年 + 国内全日制硕士 3 年（合计直接成本约 12–25 万元，接受 25 岁开始工作）——匹配主流硬工科、药学、财经政法主航道。
- [ ] **档位 III（长周期慢热贴补耐受型）**：不仅承担 8–11 年本硕博培养期，且能从容补贴临床规培期或青年律师授薪初期（25–29 岁）在一二线城市的房租生活赤字。
- [ ] **档位 IV（高净值中外合作/海硕直通型）**：在不影响父母养老与家庭抗风险储蓄的前提下，可调配 50–150 万元流动资金置换计划内中外合作名校平台与海外申硕跳板。

### 2.2 隐性成本全穿透清单（专硕不包住宿租房账 + 2+2 强制出国汇率通胀账 + 二战脱产机会成本）
- [ ] 逐项列出家长填报前极易漏算的三大资金黑洞：① 京沪部分高校专硕校外租房三年额外 10–18 万元；② 中外合作 `2+2` 后两年英美澳学费生活费飙升；③ 软工后两年按学分高收费与民办本科年均 2.5–3.5 万元学费回本压力。

### 2.3 教育投资回本周期（Payback Period）理性校准：严禁卖刚需房或举借高息债读高费合作/民办项目
- [ ] 设定家庭财务安全红线：高收费项目的四年总支出占比不得击穿家庭净流动资产安全垫。

### 2.4 对接 `D2-B` 与 `D6` 的学费上限自动拦截阈值设定指南
- [ ] 明确 `max_annual_tuition_cny`、`grad_school_budget_tolerance` 与 `early_low_pay_buffer_years` 三个机器参数的标定标准。
