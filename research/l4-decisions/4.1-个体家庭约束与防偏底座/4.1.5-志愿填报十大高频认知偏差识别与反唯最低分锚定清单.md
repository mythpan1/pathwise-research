# 4.1.5 志愿填报十大高频认知偏差识别与反唯最低分锚定清单（`L4-DEC-02.02` · 提纲占位卡）

> **当前状态**：`draft`（常青方法卡；升级第一代 `10.3.1` 决策心理学防偏机制，针对江苏专业组实战定制）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：为什么每年都有高分家庭在信息完全公开的情况下依然做出“为了不浪费 1 分踩线冲进名校大杂烩组调剂到边缘专业”、“把去年大小年断档最低分当今年稳录线”、“把四年制医学技术当临床医生报”等悔恨终身的失误？提交正式志愿前必须逐条打钩清零哪十大高频认知偏差？
- **不越界声明**：本篇提供终局防偏逐项核对清单（对接 `D6` `dim4_consensus_debias`）；具体水位与漂移数学算法详见 `4.2.3–4.2.4`。

## 二、定制拆解提纲与待填核查清单

### 2.1 分数与投档类四大认知陷阱（唯最低分锚定 / 一分不浪费执念 / 忽视组号拆并 / 错用断裂年）
- [ ] **偏差 1（“一分不浪费”沉没成本谬误）**：考分刚好压某名校投档线，觉得降 5 分去次档校王牌直录组“亏了分数”，结果 `water_level = bottom` 100% 掉进该组末位冷门专业。
- [ ] **偏差 2（单年最低分断档幻觉）**：只看去年某校偶发小年最低位次，未核查前年/大前年正常位次与计划缩减，拿断档年当保底导致滑档。
- [ ] **偏差 3（同组号跨年刻舟求剑）**：未核对当年《招生计划专刊》组内成员变动（去年 02 组是纯电类，今年 02 组塞进了材料环工或改了组号）。
- [ ] **偏差 4（无视选科与规模基数漂移）**：直接对比原始高考分而非等效位次与分段超额漂移。

### 2.2 专业与培养类三大认知陷阱（望文生义 / 盲信轻松转专业 / 拔尖班光环外推普通班）
- [ ] **偏差 5（专业名称望文生义）**：混淆医学影像学（医师）与医学影像技术（技师）、口腔医学与口腔医学技术、信息安全与信息管理、生物医学工程与临床医学、金融学与互联网营销。
- [ ] **偏差 6（“先进校大一再转专业”侥幸心理）**：忽视接收学院 5%–10% 硬上限与中外合作/强基禁转铁律。
- [ ] **偏差 7（幸存者偏差与招牌混淆）**：拿某校 30 人院士拔尖班的 80% 保研深造喜报，误作该校普通批平行组 500 名普通生的普遍出路。

### 2.3 周期与地域类三大认知陷阱（后视镜线性外推 / 江浙沪舒适区执念 / 假双保险备选）
- [ ] **偏差 8（拿过去十年景气线性外推未来十年）**：用 2016–2023 地产/教编/纯互联网红利期经验替 `2031/2034` 毕业生拍板。
- [ ] **偏差 9（唯本省本市恋家折价）**：死守南京苏州导致同分比接受武汉、西安、成都、大连、哈尔滨、东北西北 985/211 的同学低一整档平台。
- [ ] **偏差 10（假独立备选错觉）**：把同专业组捆绑或同样要求考高难研/法考的路径当保底退路。

### 2.4 锁表前 10 分钟「反悔压力测试三问」
- [ ] 强制逐组自问：“如果明天查录取结果，孩子被分到了这个专业组里我最讨厌的那个专业，且大一转专业失败，我们全家人能不能平静接受去报到？”——若不能，立即删除或调序！
