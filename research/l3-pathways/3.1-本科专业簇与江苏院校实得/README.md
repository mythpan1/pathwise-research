# 3.1 本科专业簇与江苏院校实得（`research/l3-pathways/3.1-本科专业簇与江苏院校实得/`）

- **所属层级与批次**：`L3 培养兑现与路径映射层` · `Batch 3`
- **绑定母槽**：`L3-PTH-01` 至 `L3-PTH-08`（吸收升级第一代 `5.2.16`、`5.3.1–5.3.7`，详见 [../../../index/master-map.md](../../../index/master-map.md)）

- **上下游接口**：多对多承接 [../../l2-careers/README.md](../../l2-careers/README.md) 全部岗位族规格，与 `3.2–3.4` 协同输入 [../../l4-decisions/README.md](../../l4-decisions/README.md) 收口。
