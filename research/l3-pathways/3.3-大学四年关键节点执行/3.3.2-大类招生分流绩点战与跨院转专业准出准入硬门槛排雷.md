# 3.3.2 大类招生分流绩点战与跨院转专业准出准入硬门槛排雷（`L3-PTH-03.02` · 提纲占位卡）

> **当前状态**：`draft`（常青执行方法卡；升级第一代 `6.2.1`，专门拆穿高校招生宣传“转出零门槛”话术）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：近年大批高校宣传“转专业转出零门槛、百分百自由申请”，为什么进校后真正从冷门生化环材土建文管成功转入计算机、电气、临床、法学、口腔的学生比例依然极低？大类招生内部专业分流是如何把后 50% 学生成建制推入冷门兜底专业的？
- **不越界声明**：本篇建立高校转专业与大类分流制度硬审计方法；志愿填报阶段组内水位规避详见 [../../l4-decisions/4.2-江苏新高考机制与组内风控/4.2.4-专业组纯度分级2B硬红线整组否决与water-level水位指南.md](../../l4-decisions/4.2-江苏新高考机制与组内风控/4.2.4-专业组纯度分级2B硬红线整组否决与water-level水位指南.md)。

## 二、定制拆解提纲与待填核查清单

### 2.1 拆穿「转出零门槛 ≠ 转入零门槛」话术：接收学院计划上限（5%–10%）与机试面试淘汰比
- [ ] 抽样核查多所双一流及江苏重点高校教务处《本科生转专业公示名单》与《各学院接收计划表》：计算计算机学院、电气学院、口腔/临床医学院、法学院公布的接收人数上限与实际报名人数之比（常达 `5:1` 至 `15:1`），以及接收考核（高等数学+C语言上机测试+面试）的硬壁垒。

### 2.2 法定与章程明文「100% 绝对禁止转专业」的七类身份锁死清单
- [ ] 逐条核实教育部及高校学籍管理红线：① 强基计划；② 中外合作办学专业（禁转非中外合作）；③ 艺术/体育类特长生；④ 外语类保送生；⑤ 公费师范/农村订单定向医农生；⑥ 民航招飞（非因公停飞不得随意转）；⑦ 部分高校明确规定“历史类选科录取学生严禁转入要求物理+化学的理工医专业”或“不同院校代码/异地校区之间禁互转”！

### 2.3 大类招生分流机制解剖（高考分权重 0%–30% + 大一绩点权重 70%–100%）
- [ ] 分析“工科试验班 / 理科试验班 / 经管大类”大一末或大二上分流算法：当大类内 40% 计划为传统弱势专业时，大一微积分/大物稍有闪失即不可逆掉入兜底专业。

### 2.4 成功转专业与转专业失败后的两套预案（降级补课代价 vs 辅修跨考止损）
- [ ] 核算大二转专业往往伴随“编入下一年级重读一年（变五年毕业）”的时间成本与大一选修目标院系先修课的准备策略。
