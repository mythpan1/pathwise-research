# 3.3.6 法定执业资格考证时间表与行业工作外语能力构建路径（`L3-PTH-07.03` · 提纲占位卡）

> **当前状态**：`draft`（常青执行方法卡；整合升级第一代 `6.6.2` 与 `6.6.3`）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：面对大学校园里铺天盖地的考证推销，对照人社部《国家职业资格目录》，哪些是真正决定准入与签字权的**法定硬牌照**（本科在校能考什么、毕业拿证或满工作年限才能考什么），哪些是毫无用处的山寨协会水证？英语四六级（CET-4/6）卡 425/500 分在电网、银行、保研中扮演怎样的“一票否决筛子”？
- **不越界声明**：本篇锁定全学科法定职业资格目录时间轴与实用工作外语建设路径；严禁将商业培训机构自造证书纳入推荐清单。

## 二、定制拆解提纲与待填核查清单

### 2.1 人社部《国家职业资格目录》准入类 vs 水平评价类硬核考证时间矩阵
- [ ] **大一至大四在校可考清单**：大学英语四六级（大一/大二尽早刷至六级 500+）、计算机技术与软件专业技术资格（软考中高级，以考代评国企职称）、大三下中小学教师资格证国考、**大四上全日制法本应届生报考法考客观/主观题（`LIC_LEGAL_BAR`）**、专利代理师（理工本大四应届可报）。
- [ ] **必须取得毕业证（或满工作年限）方可报考清单**：注册会计师 CPA（取得高等专科以上毕业证当年 4 月报名 8 月考，在校生不可提前考！）、执业兽医（兽医相关应届毕业当年可报）、执业医师（毕业后临床试用满 1 年或专硕规培期考）、注册电气工程师/注册安全工程师/一级建造师/一级造价师（基础考试毕业可考，专业考试严卡工作年限）。

### 2.2 大学生头号“智商税水证”避坑黑名单
- [ ] 依据人社部历次取消职业资格公告，点名清理各类非人社目录内的商业协会“心理咨询师培训合格证、碳排放管理师、家庭教育指导师、数据分析师山寨证”及非金融核心岗盲目花数万元考 CFA 一二级的低性价比误区。

### 2.3 英语六级（CET-6 ≥ 425）在保研夏令营、银行/运营商/国央企网申中的刚性机器初筛地位
- [ ] 核实各大高校夏令营入营硬条件与银行总分行、三大运营商、外企校招网申系统对 CET-6 未过 425 分直接机筛淘汰的客观现实；对比雅思 `6.5+` / 托福 `90+` 在中外合作、港新申硕与出海大厂海外岗的刚需属性。

### 2.4 工科/商科叠加“技术文档读写 + 口语会议 + 第二外语（西/德/日）”的高性价比习得法
- [ ] 提供零高价报班、依托英文原版技术文档与开源社区/外贸实战构建工作外语的执行步骤。

## 三、待抓一手信源与受控数据核验靶点

1. **官方权威目录原件**：人力资源社会保障部最新版《国家职业资格目录》（专业技术人员职业资格准入类与水平评价类全表）、中注协《注册会计师全国统一考试报名简章》、司法部法考公告。
2. **契约核验靶点**：全量对齐 `D5` 字典中的 `license_ids` 标准枚举集合。
