- **核心回答问题**：针对国家电网一批/二批、十大军工集团、大型能源石化央企与江苏 `6,030 家`“筑峰强链”专精特新龙头，大三暑期留用实习与大四秋招/春招网申笔面试的时间窗该如何精准卡位？

### 2.1 暑期实习留用黄金通道（大三 3–5 月网申）：硬科技研发大厂、专精特新小巨人与金融机构转正率
- [ ] 拆解大二日常实习垫底 → 大三暑期核心研发/工艺/业财实习争取 Return Offer 的阶梯打法，破除“等大四毕业前再找工作”的滞后习惯。
