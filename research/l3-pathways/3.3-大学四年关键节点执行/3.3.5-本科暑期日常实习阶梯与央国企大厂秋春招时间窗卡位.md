# 3.3.5 本科暑期日常实习阶梯与央国企大厂秋春招时间窗卡位（`L3-PTH-02.04` · 提纲占位卡）

## 一、本篇问题定位与不越界声明

- **核心回答问题**：为什么如今互联网大厂、头部车企、券商事务所 60%–80% 的正式校招 Offer 其实早在**毕业前一年 3–5 月启动的暑期转正实习（Summer Intern）**就已瓜分完毕？计划本科直接就业（或研二冲秋招）的学生，如何搭建“小厂日常破冰 → 大三暑期核心转正实习 → 8 月秋招提前批 → 10–12 月央国企统考 → 次年 3 月春招补录”的完整作战链？
- **不越界声明**：本篇专攻实习获取、秋春招日历与三方协议违约/应届生社保红线保护；研究生阶段导师卡实习问题联动 [../3.4-保研考研与硕博出口/3.4.6-硕士学历分行业起薪溢价回本周期与研一研二实习冲突.md](../3.4-保研考研与硕博出口/3.4.6-硕士学历分行业起薪溢价回本周期与研一研二实习冲突.md)。
