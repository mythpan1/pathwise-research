# 3.3.2 大类分流绩点战与跨院转入硬制造工业软件门槛排雷（`L3-PTH-08.02` · 提纲占位卡）

## 一、本篇问题定位与不越界声明

- **核心回答问题**：落入综合大类或弱偏好专业后，大一「大类专业分流绩点战」与「跨学院转入微电子/电气/计算机/机械硬核专业」的真实准出比例、笔面试差额淘汰率与降级重修成本究竟有多严苛？
- **不越界声明**：本篇为常青学籍排雷卡（`stability: evergreen`），用教务铁律破除志愿填报时“先进校再随便转专业”的普遍幻觉（对接 `D6` `no_blind_transfer_assumption`）。

## 二、定制拆解提纲与待填核查清单

### 2.1 宽口径大类分流真相：热门核心专业名额上限、首年必修 GPA 权重与冷门兜底分流机制
- [ ] 拆解“工科试验班/电子信息类/理科试验班”分流细则，揭示当 80% 学生第一志愿填报计算机/微电子而计划仅占 30% 时的残酷分流线。

### 2.2 跨学院转专业三重关卡：原学院转出比例限制（vs 自由转出改革）× 接收学院容量上限 × 数理编程机试面试
- [ ] 对比真正落实“转出零限制、转入考核制”的高校与仍设原专业前 `10%–20%` 准出卡点的高校，统计电气、计算机、微电子、临床、口腔等热门学院高达 `3:1~10:1` 的转入报录比（`[分析推断]`）。

### 2.3 明文禁转红线清单与转专业失败后的院内微专业/跨考止损预案
- [ ] 锁死中外合作办学、艺术体育类、强基计划、定向公费生、外语保送生等教育部明文禁止转专业的法定红线，以及大二转入硬工科常需编入下一年级多读一年的时间成本。

## 三、待抓一手信源与受控数据核验靶点

1. **高校官方原件**：在苏及外省重点高校教务处《本科生大类专业分流实施细则》《本科生转专业管理办法》及历年拟接收转专业学生名单公示。
2. **核查靶点**：通过公示名单实算热门接收学院每年实际转入人数占同级招生数的真实百分比（`[待核未知]`）。
