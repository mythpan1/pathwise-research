# 3.3.1 大学八学期关键决策时间线与大三下主备分流总控（`L3-PTH-01.04` · 提纲占位卡）

> **当前状态**：`draft`（常青执行方法卡；升级第一代 `6.1.1` 与 `6.6.4`）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：为什么大批高分考入名校的学生因大一信息差错过转专业与保研线、大三跟风盲目考研又错过大四上秋招黄金窗，最终沦为“二战失学无实习”的被动局面？大学八个学期（五年制十个学期）不可逆的四大分水岭节点究竟卡在哪几个月？
- **不越界声明**：本篇提供全专业通用的八学期甘特总轴与止损开关；转专业、GPA、竞赛、实习与考证专项细则分别展开于 `3.3.2–3.3.6`。

## 二、定制拆解提纲与待填核查清单

### 2.1 第一关口（大一上 9 月—大一下 5 月）：入校选拔班机考、数理基础课保绩点与转专业/分流生死战
- [ ] 梳理新生开学报到周即举行的“拔尖基地/卓越班/教改班二次选拔考试”（高三暑假必须衔接准备微积分与 C 语言/英语）、入党申请书递交时点（选调生预备党员党龄倒推线）及大一末分流节点。

### 2.2 第二关口（大二上—大三上）：专业硬课攻坚、白名单竞赛/实验室进组与首份专业实习破冰
- [ ] 明确保研边缘排位自检法则：大二结束时对照本院往届推免边缘 GPA 线，决定是全力冲综测加分保研，还是果断转入“考研硬课 / 工程项目暑期实习”赛道。

### 2.3 第三关口（大三下 3 月—8 月，`T+3` 终极分流决断口）：严禁“假装考研逃避秋招”
- [ ] 建立四路互斥资源分配矩阵（保研预推免 vs 统考考研 vs 3–5 月找暑期转正实习冲秋招 vs 语言标化出国港新申硕），制定“考研模拟达标线 + 秋招保底 Offer 双轨止损纪律”（例如先拿一份国企/制造业保底签约再安心冲 12 月初试）。

### 2.4 第四关口（大四上 9–12 月秋招公考 → 大四下 2–5 月春招调剂与应届身份保护）
- [ ] 锁定国考报名（10 月中旬）、江苏省考/选调生报名（11 月上旬）、国家电网一批（11–12 月）与考研初试（12 月下旬）的高度重叠冲突应对方案，以及毕业前慎签第三方劳务社保以保留应届生身份的红线。
