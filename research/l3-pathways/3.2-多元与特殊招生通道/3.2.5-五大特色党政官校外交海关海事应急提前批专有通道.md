# 3.2.5 五大特色党政官校外交海关海事应急提前批专有通道（`L3-PTH-08.05` · 提纲占位卡）

> **当前状态**：`draft`（提纲已就位待填充正文；独立拆解升级第一代 `5.6.3` 并补全海关、消防救援与海事提前批）。全文严格区分 `[已核实事实｜出处]`、`[明示假设]`、`[分析推断]`、`[待核未知]`。

## 一、本篇问题定位与不越界声明

- **核心回答问题**：常被坊间混为一谈的“提前批部委特色官校”——北京电子科技学院、国际关系学院、外交学院、上海海关学院、中国消防救援学院以及大连海事/上海海事/武汉理工航海轮机提前批，哪些是真正**自带全员/高比例内部考录或授衔分配（如北电科、消防救援、上海海关提前批海关管理）**，哪些早已改为**完全市场化自主择业（如国关、外交、社科大、青政）**？
- **不越界声明**：本篇逐校证伪“包分配传言”并核清提前批特许专业边界；军校与公安警校已分别拆入 `3.2.3` 与 `3.2.4`。

## 二、定制拆解提纲与待填核查清单

### 2.1 北京电子科技学院（中办直属）与中国消防救援学院（应急部直属）真高确定性入编机制
- [ ] **北京电子科技学院**：核查其在江苏省提前批政审面试流程、全员密码通信网安涉密培养以及大四参加党政机要密码系统内部公务员招录的真实机制与去向层级。
- [ ] **中国消防救援学院**：核查其参照军校模式“入学即入队、免学费发津贴、毕业考核合格授消防救援衔定编分配国家综合性消防救援队伍”的硬规则与高危执勤纪律要求。

### 2.2 上海海关学院（提前批「海关管理 / 海关稽查 / 海关检验检疫安全」vs 普通批普通经管法）
- [ ] 严分上海海关学院提前批特设海关专业（对应国考全国各地海关仅限海关管理等专业报考的巨量岗位池，高上岸率但需注意部分岗位在边疆口岸海关）与普通批国贸/税务/英语专业的本质差别。

### 2.3 外交学院与国际关系学院：去“包分配”迷思后的外交部遴选、选调保研与外语优势实况
- [ ] 核查两校官方就业质量报告：明确其并无包分配特权，客观评估其在外交部/涉外部门公务员招录、高保研率及北京部委资源上的真实竞争力。

### 2.4 航海技术（`081803K`）与轮机工程（`081804K`）提前批：视力身高体检、跑船高薪与海事局上岸路径
- [ ] 梳理大连海事大学、上海海事大学、武汉理工大学、集美大学、南通大学等提前批航海类专业的降分幅度、船员适任证考试及海事局直属系统国考对口优势。

## 三、待抓一手信源与受控数据核验靶点

1. **官方权威原件**：北京电子科技学院年度招生章程与江苏政审通知、上海海关学院招生章程及毕业生就业质量报告、中国消防救援学院招生简章、外交学院/国际关系学院招生章程、大连海事/上海海事提前批章程。
2. **公考职位核对**：国家公务员考试海关系统、海事系统职位表对 `海关管理`、`航海技术`、`轮机工程` 专业代码的精确限定条数。
