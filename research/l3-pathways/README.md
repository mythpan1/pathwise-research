## 二、`1B` 结构代理、`403` 降级与下游反向回灌铁律

1. **普通批普通生可及性基线**：聚焦评估**普通本科生**（非极少数拔尖实验班个例）的实际课程容量、实验学分、分流比例与校招录用去向。
2. **`1B` 结构代理严格边界（冲突即转未知）**：缺同届细分项目升学/就业分母时，实验必修学分、一级硕博点、头部雇主进校宣讲名单与特殊班条款仅支撑**标注 `[结构代理降级]` 的保守默认序与 1–3 条招办线下核实单**；**若多项代理指标相互冲突，一律降级标为 `[待核未知]`，严禁简单投票取多数**。
3. **官网 `403` 第三方交叉验证降级**：官网不可达时允许用阳光高考、主流高招平台或高校官方认证公众号至少两路独立交叉核验，并显式标明 `[第三方交叉降级]`。
4. **下游硬门槛反向回灌**：若实证发现普遍刚性读硕或江苏专业组混编限制推翻上游 `L1/L2` 既有假设，必须在同一 PR 联立修订上游卡片或在 [../../index/manifest.json](../../index/manifest.json) 标记 `needs_reverify`。
