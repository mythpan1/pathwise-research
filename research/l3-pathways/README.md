## 一、本层放什么（核心映射与反向回灌职责）

本层多对多承接 [../l2-careers/README.md](../l2-careers/README.md) 的岗位族准入规格，向下对接教育部《普通高等学校本科专业目录（2026 年）》精确专业代码、江苏普通批可及招生院校梯度与大学 4–7 年执行规划，并为 [../l4-decisions/README.md](../l4-decisions/README.md) 提供可兑现度依据：
1. **本硕准入分流与执业边界锁定**：区分“本科直就可达”“对口硕士硬门槛”与“法定执业资格/公考目录专业代码刚性绑定”；若实证发现某岗位普遍刚性要求硕士或特定混编限制推翻上游 `L2` 假设，必须触发**反向回灌**联立修订上游卡片。
2. **江苏普通批可及院校的普通生实得训练比较**：聚焦评估**普通批可及项目内的普通本科生**（非极少数拔尖班个例）在 `target_regions` 与 `graduation_cohort` 下的真实训练、升学分母与行业渠道壁垒。
3. **志愿与大学 4–7 年执行规划一体化时间轴**：锁定大一分流/转专业真实准出准入线、大二核心实验与白名单竞赛/实训、大三下保研/考研/秋招实习分流点及毕业备选切换口。

## 二、锁定信源与 `1B` / `403` 严格边界规则

1. **首选一手信源**：高校官网最新适用届别本科培养方案、教务处转专业与推免接收细则、分母明确的毕业/升学去向表、目标雇主实际拟录用院校学历公示。
2. **高校官网 `403` 第三方交叉验证降级**：官网 `403` 时允许采用教育部阳光高考、主流高招平台、高校官方认证公众号等至少两路独立交叉核验，并显式标注 `[第三方交叉降级]`。
3. **`1B` 结构代理严格边界（防把学校招牌误当普通生实得）**：
   - 当缺乏同毕业届细分项目升学/就业分母结果证据时，实验学分、硕博点、校招宣讲名单与特殊班条款仅作为**结构线索代理**，只能支撑**标注 `[结构代理降级]` 的保守默认序与 1–3 条招办线下核实单**，严禁据此伪造精细成功概率或强行大幅换序；
   - **冲突即降级铁律**：若多项结构代理指标相互冲突（如拥有一级博士点但普通班实验必修极弱或捆绑高淘汰分流），**严禁简单投票取多数，必须直接降级标为 `[待核未知]`** 并列入招办必核项。

## 三、严禁放入本层的内容

- 严禁为极少数人特殊班微细则、冷门小证书或极端个例单独开卡（一律只作所属 `L3-PTH-*` 主干卡内附注或招办核实项）；
- 严禁把“前 5%–10% 绩点准出 + 差额笔面试”的高门槛转专业当作混编冷门组的保底退路；
- 严禁写入受控招生底表原始行（接口见 [../../data/README.md](../../data/README.md)）、真实考生姓名或本机绝对路径。
