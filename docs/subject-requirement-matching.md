# 已选科目与招生要求的匹配

本模块用于高三考生已完成选科后的志愿筛选，不推荐或评价选科组合。检索对象是考生省份、招生年份、招生渠道、批次以及院校和专业（或当地招生计划使用的专业组）对应的选科要求；具体招生资格及投档规则还须另行核对。

## 输入与来源

记录考生省份、年份和已选科目，按省份当年规则确认科目名称、首选／再选关系；记录待查招生单位、专业或专业组、招生渠道和批次。依据当年省级招生计划和考试机构公布的适用选科要求，并对照高校正式招生章程及相关更正。先核对适用制度、科目数量及首选／再选身份；输入缺失、矛盾或不合法时，不输出有效匹配结论。未取得适用资料、无法辨认专业组或规则有冲突时，标为“待核实”，不猜测资格；未找到要求不等于官方明确“不提科目要求”。

## 匹配方法

- “不提科目要求”：选科条件本身不构成限制；不等于满足其他报考资格。
- “均须选考”：要求列出的科目全部包含在考生选考科目中；缺少一门即不满足该选科条件。
- “选考其中一门即可”：列出的可选科目至少满足一门；一门也没有则不满足。
- 首选、再选或其他特定模式：按该省当年发布的具体规则解释，不把不同模式生硬套成相同结构。

复合条件按官方原文保留首选、再选及其他要求之间的“且／或”层级，先逐项判断再组合；只有未知项影响最终判断时，结果才标为待核实。

输出每个招生单位的选科匹配结果：满足、不满足或待核实，并附当年院校、专业组、专业代码、招生阶段、规则原文位置、来源、适用年份和判断理由；不适用的层级明确标注。组与成员结论不能互相自动外推，也不能推定调剂或分流范围。条件是分层的：选科匹配不代表其他资格已满足，也不表示能够投档或录取。专业组内专业范围、体检、资格及具体通道要求分别核对；不凭专业大类或类似院校推定个案。

## 示例（虚构，仅演示逻辑）

在某省某年，考生已选物理、化学、地理。假设专业 A 公布“物理和化学均须选考”，则 A 的选科条件满足；假设专业 B 公布“政治或生物选考一门即可”，则 B 的选科条件不满足；假设专业 C 的当年要求未取得，则 C 待核实。以上不是实际招生规则或录取建议。

## 与其他知识模块的连接

先根据省份、年份、已选科目和招生渠道按需加载相关规则与专业数据，再将通过选科条件的候选项交给资格、招生计划、位次与录取竞争的后续处理；这些是接口依赖，不表示模块或数据已实现。院校专业对应的实际培养路径和职业入口再与政策、产业、人口形成的毕业或求职目标年份情景连接，不能与当前招生年混同。不同选科组合的可选集合可能相同、包含、相交或不相交，也可能没有专属项；由实际规则生成交集，不预设固定组合排名。后续材料须注明来源和时效，不把旧库覆盖率或个案当作现行事实。
