## 历史计划：路径与有界任务

- 必须通过 **Chat Work 实际已安装的私有 Tavily 插件 MCP 路径**使用工具；直接 API 测试脚本、历史 DSH/ACP 入口或模拟结果不能替代这条路径的验收。入口不可用时记阻断，不换入口冒充通过。
- 执行前选定获准、非敏感的代表性测试问题，记录实际插件版本、入口、执行运行、请求/可见报告模型与思考强度、预计调用预算及停止条件。用既有运行/步骤/来源模板，不增加重型系统；不因测试启动下一研究单元。
- 在同一有界任务内做少量有代表性的 **Search**，以及**一次 `mini` Research 的 create → status → result**；取得任务 ID 后沿用同一任务，不把正常有界状态查询当新建。具体参数以实际工具 schema 为准，不猜接口或伪填回执。
- 不额外调用 Usage/余额探测，不逐个探测 500 个 key，不新增人工每日调用上限；单次任务仍须有明确预算和停止条件。保留插件本身适用的已授权限制，不通过手工换 key/账号绕过。创建请求结果不明时不得自动重发、轮转或重建任务；按现有回执核查，无法确认则停止并报告。

## 历史验收条件与留存

1. 记录脱敏的真实调用参数、响应/错误、任务 ID、实际版本与入口、输出产物及可核时间/哈希。模型请求、可见配置、运行报告与后端身份分开，不声称已验证未知项；调用失败或未执行据实登记；未暴露的版本等记未知，不为补字段探测或读取凭据；槽位连续性如需留存仅在受控本地，仓库索引不含匿名槽位或提交 token。
2. 对 Search 与 Research 的代表性主张读取原始来源并逐项对照，区分来源事实、摘要/推断、冲突与待核实项；模型输出不能代替原文或独立证据。无错误也不编造错误；未取得原文、状态或最终结果就不能声称对应环节通过。
3. 验收覆盖真实入口可调用、Search 可用、一次 mini 任务可创建并取得状态/结果、产物可检查和引用可追溯。成功回执不单独证明内容正确；结果不理想、失败或入口受阻都可作为真实结果交付，但须明确未通过或未完成的范围。
4. 保留原始来源、实际回执及中间产物于获准的受控位置，仓库只放获准的脱敏摘要/索引、必要摘录和版本/哈希；不上传 key、凭据、机器路径或完整内部日志。向获授权审核者提供实际材料或说明访问盲区，沿用[证据与交接要求](agent-workflow.md#每个阶段的证据不能丢)。

只有实际完成并经审核确认的**特定版本、入口及已覆盖能力**，才标记相应验收状态。当前 Search 为修复后的单次可用结果，mini/pro 为单次链路成功但内容质量未通过，runtime 版本仍未知，不能认证具体部署。使用遵循 Search → 原文 → Astra → 独立审核主线；Research 可在未来任务的既有授权和预算内按缺口选用，不因本次负面结果永久禁用，也不作为事实证据。不为每次正常使用重复冒烟或重开本单元测试。
