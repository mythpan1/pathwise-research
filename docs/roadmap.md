# 建设计划

## 当前计划（2026-10-26）
完整框架建设是当前交付，不再把小范围试用当最终目标。小样本用于检验方法，完整设计、内容填充、现实验证和软件建设分别验收。详见[框架](research-framework.md)及[本次决定](decisions/2026-10-26-complete-research-framework.md)。

### A. 完整设计与采用
交付三线连续研究、职业培养个人连接、来源判断改判、覆盖计划和配套模板，并完成实际版本独审、必要返工和仓库检查。本稿不预填已通过或已合并，结果在 PR / reviews 维护。
验收：结构、模板和导航一致，现有强弱案例可如实表达，没有靠删掉未知关系才能使用；不以新增目录数量验收。

### B. 系统填充
从[覆盖与推进](../research/coverage.md)给已有成果建立归属与缺口，再对未评估领域形成概览，按选择影响和关键未知排序。每轮深入一条连续问题，接到任务、职业入口和培养，不重复方法试水，不一次启动所有行业研究。
验收：每项已有判断可追到依据和版本，未覆盖可识别，跨链关系有明确机制，下一任务理由清楚。具体新增调查仍由任务授权限定。

### C. 应用与持续校准
对具体毕业群体形成公共路径比较，在获得相应个人资料及授权后做个性化比较；按政策、产业、人口和培养的变化更新受影响判断。实际使用时复核招生、资格与培养资源时效。预测在目标时点复盘，不能用事后信息覆盖旧版本。
验收：比较包含条件、备选、转换成本与改判信号，不给无依据总排名；未知和不可行路径清楚。

### D. 工具建设
只有重复工作明确形成瓶颈且任务获准时才增加采集、索引、校验或界面。本轮不部署数据库、自动采集或新门禁。
