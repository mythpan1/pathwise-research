# 建设计划

## 阶段 0：项目骨架

- [x] 确认中英文名称和研究定位。
- [x] 建立本地目录、研究框架和模板。
- [x] 写入 Agent 协作规则与本地资料忽略规则。
- [x] 创建 GitHub 私有仓库并同步新建骨架。

验收：目录和文档可用，远端为私有仓库且只包含新建骨架；现有“学业”仓库资料未导入或上传。

## 阶段 1：跑通一项小研究

- [ ] 选定首个地区、年份、对象和研究问题。
- [ ] 完成来源记录与必要的数据整理。
- [ ] 形成一份有证据、适用范围和限制说明的报告。
- [ ] 根据实际使用发现的问题调整模板。

验收：关键结论可以回到原始证据，待核实事项清楚，项目负责人确认可用。

## 阶段 2：沉淀可复用资料

- [ ] 根据首批研究建立确有必要的字段和命名约定。
- [ ] 整理院校、专业、职业之间可核验的关联。
- [ ] 确定哪些数据需要定期更新及其来源。

验收：新研究能复用既有资料，并能识别年份、地区和口径的差异。

## 阶段 3：按实际需要建设工具

- [ ] 根据重复工作决定是否增加采集、清洗、分析脚本。
- [ ] 根据真实使用需求决定是否建设查询界面或规划应用。

验收：每项工具解决一个已出现的问题，并有对应的输入、输出和检查方法。
