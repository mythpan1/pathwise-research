# 志愿投档机制：规则核对与结果推演

本模块为高三考生规划填报顺序和风险，不替代省级考试机构当年招生规定、招生计划及高校章程。按省份、年份、招生渠道、批次、轮次和科类检索适用规则；平行志愿、顺序志愿及特殊渠道不得混为一类。

## 规则输入

记录适用批次和轮次、志愿单位、可填数量、投档排序与同分处理、顺序检索方式、计划与资格要求、投档后的学校录取办法、专业分配及调剂范围、退档后可参与的后续环节。每条保留来源、发布日期、适用对象与年份；规则未找到、冲突或不确定时标记待核实，不用旧省份数据填补。只有已确认不满足的条件才能据此排除；未核实条件不当作满足，也不当作不满足而跳过。未知影响结果时保留条件分支，只限制依赖该未知项的结论。

## 条件推演

先区分“资格满足”“被投档”“被院校录取及具体专业”三个阶段；某一阶段成立不自动推定后续成立。对于官方规则明确采用分数或位次优先、按顺序检索且单轮一次投档的情形，按考生排序及志愿顺序推演：第一项不满足投档条件时继续检查后续项；某项被投档后该轮次不再按其他志愿继续检索。院校依本年章程及政策决定录取、分专业或退档。具体规则必须以当年省份和渠道为准，不能把一种模式套给全部批次。仅凭个人位次、招生计划和历史投档或录取线，不能确定当年真实投档结果；缺少实际竞争及投档过程信息时，只在明示假设下推演可能结果。实际投档、录取或退档状态须以官方查询或通知核实。

在院校专业组等涉及专业分配的场景中，明确所填专业、可能的调剂范围、是否服从、身体及单科等实际要求；不可接受的专业、收费和校区结果单列。不得默认服从一定录取、转专业一定成功或退档后一定能回到本轮后续志愿。征集、下一批次及其他渠道能否参与，须以当年规则和考生状态核实。

## 输出与连接

列出每个候选志愿的投档单位、顺序、关键资格、专业分配和退档风险、未知项、来源及生效范围。结合历年位次比较提供条件参考，不把历史最低线或“冲稳保”标签当录取保证。对已确认可行的候选及注明前提的条件候选按需检索实际培养路径与职业入口，与政策、产业及人口变化对应的毕业／求职年份情景双向核对。现有模块只提供方法，具体省年规则及候选数据需按需获取。

## 旧库取舍

吸收先理解投档、再设计顺序与风险的结构。旧库省份志愿数量、调档比例、调剂编码、固定梯度和概率未逐项核验，不作为现行规则。旧库声称所有资格都会在投档前检查，不作普遍结论。
