# 高考志愿与未来职业规划：项目总入口

## 目标与主线

项目面向即将高考的高三考生，形成供 Agent 按需组合检索的知识库：从国家政策、产业变迁、人口结构三个开放的上端视角，推演考生约十年后的就业情景；从省份、选科、分数位次、招生渠道、院校和专业的下端条件出发，经过培养路径与职业入口，与上端汇合，提出当前最合适的志愿规划及备选。

**当前数据建设范围（2026-11-01）：**以江苏生源考生、江苏当年招生规则及已购江苏地区数据为底座，比较全国在江苏招生的省内外院校；学校所在地、考生生源省及未来就业地区分开，后者按考生实际条件选择。用户未购买优志愿其他生源省份权限，本阶段不要求建立全国生源数据。上端政策、产业、人口研究可涉及全国及相关地区，不因生源限定而排除。

三条主线是可以交叉的研究轴，不是只研究三个行业。上端容纳成熟、转型、新兴及收缩领域，沿需要变化的产业链、地区和职业持续拓展；政策和人口通过具体机制改变机会，不根据标签机械推专业。下端不以性格、兴趣画像或家庭照护责任给考生预设路径。

## 时间轴

以考生实际入学年为起点，分别观察本科约四年毕业、继续读研后的毕业、以及毕业后两三年的职业发展；约十年是远期就业判断的主要锚点，并非要求所有人经历相同学制。短期招生条件与不同就业时点要按对应年份组织和更新，不能把目前招聘热度直接当作十年后结论。

### 跨路径时间与判断依据

为同一考生同时保留三类时间：当前报考与录取窗口、本科及可能的研究生或其他培养阶段、进入职业并成长的目标年份。学制按实际专业与路径调整；医学、博士或其他长培养周期不强行压到“四年本科＋三年硕士”的示例。近端以适用规则和可比历史招生数据形成具体方案；中远端结合培养条件及就业情景提出有方向的路径判断，不以时间远为由只给抽象框架。

### 高校调整信号如何与上端结合

专业增设、撤销、招生计划和培养方案变化，是观察高校培养供给调整的信号，也可能影响考生可以选择的路径。对每一项，先标明学校、专业、日期、变化内容和实际生效届别，再比较对应产业、政策、人口条件与目标毕业年；单一高校调整不等同就业需求，也不预设固定领先或滞后年数。可把信号作为提出假设和改判的输入，具体方向和时滞由相关证据或明示条件判断。

## 上端：从变化推导就业情景

- **政策：** 政策问题、目标与工具怎样改变投资、成本、准入、资源配置和主体行为，经产业及职业环节传导。
- **产业：** 产品和需求、技术、上下游、组织、竞争和地域迁移怎样改变任务、岗位、招聘入口及所需培养。
- **人口：** 队列、地区迁移、需求与劳动供给、退休补员怎样改变服务与产业需求、企业响应和竞争。
- **联合判断：** 对目标地区与就业时点，结合相关主线推导基准及有实际区别的情景，写方向、强弱理由、成立条件和可能改变结论的信息。按主题需要组合，不要求每条情景凑齐三个视角。

就业研究覆盖多个行业和职业，任务变化、新人入口、进一步成长和劳动力供给分别判断。现有少子化、CO₂、机器人和视频素材可提供起点，不代表完整市场。

## 下端：从考生条件到志愿方案

1. 确定省份、报考年份、考试模式、科类与选科组合、成绩和位次；分数未公布时可以用模拟位次和假设做预规划。
2. 按该省该年的规则分别检查普通志愿、强基、综合评价等适用渠道及其资格、时间、选拔和填报方式；不同省份和学校要求分别记录，不能以一种渠道替代另一种。
3. 用学校及专业组／专业的适用选科和招生要求筛选候选。不同选科组合既可能重合，也可能受到不同约束；以目标省份、年度与学校正式要求为准。
4. 结合往年可比录取或投档位次、当年考生位次、招生计划、批次与专业组变化等，估计当年候选的进入机会，形成冲、稳、保及替代选择。识别口径变化，必要时用多个情景或区间校准；不能因为当年实际结果尚未产生而停止推导，也不能把估计写为已发生的结果。
5. 结合各渠道的顺序、约束和风险，比较候选院校专业及填报顺序，给出主方案、备选、理由和需要重点复核的变化。最终给出具体报考学校前，专门核验报考当年本省及各校的招生简章、专业计划、选科、渠道资格、计分与录取规则，并据此更新推荐；历史学校名单与规则仅是对应年份参考，不永久锁定候选。

## 两端汇合：专业不是职业的唯一标签

使用多对多关系组织路径：

省份与选科及位次 → 可报渠道 → 院校专业候选 → 培养内容与本科／读研路径 → 目标地区及年份的职业入口 → 产业、政策、人口情景。

同一专业可以通向不同职业，同一职业也可能有多个专业入口。对每条候选，比较入学可能性、培养内容、可能继续深造的时间投入、主要就业入口、上端情景、可迁移出口及替代方案。优先利用与考生实际候选相连的行业和职业，不先读取整个知识库。对部分信息未完成核验的路径，保留明确条件的候选判断并指出会改变方案的关键事实。

## 推导与证据

推导是本项目主要工作方式。先整理已有证据、考生条件及需要假定的因素，沿机制提出可解释的方向判断和方案比较；再核对会改变资格、方案排序或关键方向的证据，持续校准。最终输出应给出当前倾向及理由、风险和备选，不以“可能有变化”替代规划。

网络和旧库都可提供事实线索和既有推导。事实线索追溯可确认的原始来源与适用口径；加工观点不直接当已确认事实。既有推导的方法、逻辑与方向可择优吸收，缺失步骤可以重建并注明补充内容，再用事实校准。不能因没有确定结果或每一步缺实证就一概摒弃。旧库依用户指令从顶部按章审读，逐批择优吸收、独立审核并落实；事实和推导分别处理。

## Agent 按需组合与知识组织

具体模块/目录、八类知识单元、年度组身份、条件关系与分阶段检索输出以[知识单元和组合契约](planning-knowledge-contract.md)承接下述原则；填写用[扩展模板](../templates/planning-knowledge-unit.md)，反例见[合成验收](../research/admissions/planning-framework-acceptance.md)。它是现有框架的接口细化，不代表真实数据或自动检索已经建成。

各模块提供可引用、可更新的最小知识单元，而非把完整资料一次塞入上下文：

- **考生与招生：** 省份、年份、考试模式、选科、位次、渠道资格、规则和招生计划。
- **院校专业：** 学校、专业组／专业、选科要求、历年可比位次、培养方案、学制与可取得的训练。
- **培养与职业：** 课程实践、学历或资格、毕业时点、职业入口、成长与可迁移出口。
- **上端研究：** 政策、产业、人口机制及就业情景；按行业、职业、地区和目标年份建立关系。
- **证据与判断：** 来源身份、年份地区口径、事实或推断、前提、逻辑、版本和改判信息；记录知识单元之间的连接。

Agent 从考生条件筛选可报对象，再按专业、职业、地区、时间取相关上端知识，拼接培养路径与情景，比较并输出方案；只加载本次需要的单元，发现缺口时按影响程度补查或设条件。按版本保留推导、来源、更新与受影响结论，避免材料被改写后失去追溯。
