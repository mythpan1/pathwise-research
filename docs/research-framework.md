# 知途研究：完整研究框架
版本：2026-10-26。设计与采用状态由对应 Issue、PR 和独立审核记录维护。

## 一、项目目的、设计完成与内容完成
本项目研究中国未来十年的政策、产业变迁、人口结构变化如何改变职业入口、成长和转换条件，并服务今天的高考志愿、培养与职业路径比较。志愿填报是重要应用，不是研究的全部；项目也须支持学习过程中的调整、升学和就业转向。

**小样本用于检验方法可行性，不是把最终框架缩成小样本框架。** 本版给出从公共研究到个人应用、从来源到改判、从覆盖规划到审核采用的完整工作结构。完整指必要层次、连接、产物、责任和更新方式能够贯通，不指已经取得所有行业资料、证明所有预测或完成生产软件。

三条主线固定为政策、产业变迁、人口结构变化。国际环境在具体传导相关时作为背景接入，不单列主线。研究总图见[架构](research-architecture.md)，推演边界见[研究方法](research-methods.md)，执行和审核唯一主流程见[协作闭环](agent-workflow.md)。本文件说明研究如何组织，不另造相互竞争的调度规则。

## 二、整体结构：连续主线、共同连接、决策应用
整体由四部分组成：
1. 三条连续研究主线：各自保存对象历史、变化路径和后续观察，不被单篇新闻或单个任务切碎。
2. 跨主线连接：把相关变化对齐到具体价值链环节、主体、地区与时间，解释任务及职业机会怎样改变。
3. 学业与职业应用：把职业要求接到真实培养、资格和个人条件，形成可比较、可修订的路径。
4. 共同基础：来源、判断、关系、版本、覆盖、审核与更新，支撑前三部分而非成为研究终点。

研究不是三个专题相加，也不是唯一的“政策→产业→人口→职业”流水线。技术、市场、人口、制度都可能是起点；反馈按时间展开。公共研究允许先形成有方向的条件判断，再在关键节点取证，不必等全链实证才往前。

### 2.1 政策：持续的问题及跨期政策谱系
连续对象是一个治理或发展问题，而非文件标题。依次保留：
- 问题如何形成、已有产业和制度条件；
- 目标及取舍，历次是否延续或调整；
- 工具怎样改变特定主体的收益、成本、资格、资源或退出选择；
- 部门、地方、资金及组织执行；
- 主体实际响应、观察结果和下一期调整。

选材包括长期战略与规划、产业工具、部门和地方实施、资源执行及评价；《求是》等文章用于理解问题意识、政策论述与专家视角，须区分作者身份和文章性质，不能一概当作具有执行效力的规范文件。“十五五”材料是跨期规划入口之一，不是政策主线的全部。优先研究对产业活动有具体连接的政策；教育人才材料可作培养制度的辅助，不用口号替代任务和入口分析。

同一目标下工具可以改变；目标延续、工具变化、执行强弱和效果不确定性分开。没有总实施文件不妨碍提出条件推演，但各部门适用对象和执行记录不能由总纲自动补齐。行业困难先促成政策加码也是竞争解释，不能把加码后承压直接解释为政策无效。

### 2.2 产业变迁：连续价值链及能力重组
连续对象是某种变化怎样重组产品或服务价值链。至少识别上游投入和设备、核心工艺及组织、产品与客户、支付采购、配套服务及退出回收；不要求每条链有相同环节，也不把不相关产业强接成物料链。

变化来源包括技术工艺、产品用途、需求、成本、生产组织、成熟扩散、集中、外包、替代与退出。覆盖新兴和成熟产业，也覆盖收缩与公共服务，不能只追技术突破。

判断依次区分：技术可行、可重复工程运行、客户采用、规模扩散。不同产品路线的指标不得互借；商业化时点影响专用入口，不自动消灭科研训练或具有独立需求的中间产品。后者仍须有独立成立条件，不能用“通用能力”绕开经济性和实际训练问题。

企业和公共机构分别研究：企业关注需求、订单、成本、利润和回款，公共机构关注职责、预算、支付、服务量和承接方式。规模、收入、劳动投入、在岗、招聘、补员、新人入口分别记录。任务可以转给供应商、外包单位、用户或机器，不能只看原企业岗位。

### 2.3 人口结构：需求、劳动供给和接续
连续对象是地区、年龄队列、家庭结构及其变动。研究规模、存量与流量、迁移、劳动参与、技能和人员接续，不把少子化等同教育，不把老龄化等同养老。

需求端追踪：需要→可获得和支付条件→实际使用→组织工作量→任务安排。人均收入或单价上涨不自动抵消人数下降对实际工作量的影响，替代解释须有足够规模和机制。

供给端追踪：相关队列→招生分流和培养完成→资格与参与→地区和职业流向；既有从业者的退出、返聘、补招与经验接续另列。供给不仅影响竞争，还可能改变企业自动化、选址、外包和组织，随后反馈到需求及岗位。

以目标入学、毕业和求职年份对齐传导，不能把当前出生变动直接赋给几年后的大学毕业供给。全国总量、局部迁移和具体职业供给不可混用。

## 三、研究对象与颗粒度：链、判断包、来源各司其职
- **连续研究链**：长期追踪的政策问题、产业价值链或人口结构对象。用稳定标识、当前入口及修订历史维护。
- **判断包**：为链中的一个有边界问题形成的产物。含对象、条件、重要判断及关系、职业或培养连接、改判点和迁移边界；不是把链切成互不相干的报告。
- **来源记录**：材料实际支持什么及如何复核。一个来源可服务多个包，包必须引用准确位置。
- **决策输出**：面向某个毕业群体或个人，把相关包综合成路径比较；不改写公共事实迎合偏好。

每个判断包指回所属连续链，说明承接的判断、影响的关系和下一连接。无法归属的新线索进入素材待判区，经确定问题后再形成链，不因一条视频自动新建产业专题。

稳定标识采用“研究链标识/判断标识@版本”即可；来源标识按现有研究命名空间限定，避免各目录的 S001 被误当同一材料。无需先部署数据库。小问题可在一份报告内表达全部必要信息，大问题使用链接拆分，不按字段数量考核。

## 四、证据、判断与关系：完整而不僵硬的记录
每个重要判断须保留：
1. 对象、主体、地区、时期、术语口径和判断方向；
2. 来源实际陈述、经核事实、机制推断、未来条件情景或个人价值取舍的类型；
3. 支持、相反材料、前提和当前未知；
4. 对哪些后续判断有影响，作用机制、时滞及实质分支；
5. 哪种新观察会使其保留、增强、收窄、改写、撤回或继续未知。

关系不只记录箭头：需要说明连接的是谁、通过何种行为或约束、在什么时间发生；不同主体、地区和时期的关系要说明桥梁。允许一对多、多对多、并行路径和跨期反馈，不允许反馈产生的推断回填成证明自身前提的独立证据。

来源直接、权威、时效和适用范围分别判断，不合成无依据的总分。多个报道转引同一原件，不算多个独立支持。原文、摘录、分析和建议分开；视频与评论可提出视角和线索，不因表达有说服力就成为论证事实。Search 找线索，原文核对后才能支持对应事实；Research 综合报告不替代原文，详见[工具协议](tavily-protocol.md)。

保存可获准留存的原件或受控位置、准确链接、发布及访问时间、原文位置和版本/哈希。访问失败、截断、缺页及未取得原件如实标注；摘要不能替代丢失内容。版权、隐私和上传范围优先于留存便利。

## 五、从产业任务到学业职业选择
这部分是三个主线共同服务的应用，不是新增主线。

### 5.1 任务与用工
追踪任务变化、归属及组织响应：增员、加班、自动化、外包、转岗、退出。分清谁付费、谁承接、谁签约用人；建设期与运营期、研究与生产、熟手与新人不同。原岗位减少可与其他环节任务增加并存，不能未经比较就宣布净增或净减。

### 5.2 职业机会
至少比较新人入口、实际竞争范围、劳动条件与质量、持续性、成长和转换空间。明确所用指标，例如实际合资格参与者相对可进入岗位；资格人数不等于参与人数，招聘总数不等于应届可进入数。竞争变化与入口规模可以不同向。

尚未形成稳定职业名的新任务，先记录工作内容、承接主体和能力组合；不得虚构成熟职业、招聘规模或专业对口。成熟行业里的新任务同样重要，不能只有前沿技术才有研究价值。

### 5.3 能力、培养和资格
职业、任务、能力、专业、院校培养为多对多关系。分别记录：
- 条件推演得到的能力需求；
- 用于说明的训练项目；
- 实际培养方案、实践机会、考核与成果；
- 资格要求、雇主接受和真实进入情况。

课程名称或学历不能单独证明能力，实践成果不能自动证明雇主认可。学校具有资源不等于普通学生实际能获得；核准适用届别、渠道和参与条件。招生及资格规则在实际决策使用时核验最新版本，研究材料的历史年份不自动更新。

### 5.4 路径比较与个人应用
面向公共研究，输出哪些路径值得提高关注、哪些单一出口风险上升、哪些能力迁移具有条件优势。针对个人再加入选科、成绩、资格、地域、预算、能力发展、兴趣和价值取舍，形成可行路径集合，不给所有人一个排名。

面向高三学生的具体报考比较，先明确省份、招生年份、选科、成绩及其适用位次、招生渠道，并核对该省该年该渠道的规则与来源版本。成绩和位次须注明适用年份与口径，历史数据不能直接当作当年门槛；缺项保留待核。报考资格与录取竞争分开：先按选科和其他当年规则判断能否报考，再结合适用位次、招生计划及可比历史数据讨论竞争，不把具备资格写成能够录取。

对每条院校／专业／渠道候选，分别连接进入条件、可实际获得的培养与实践、预计毕业时的职业条件情景、主要出口与备选，以及学习投入、机会成本和转向其他路径的资格、补训、时间与费用成本；写明连接依据、缺口和下一决策时间，不用专业名称直接替代训练或职业结论。

时间尺度分开使用：近端回答当前志愿与当年录取条件，中端比较入学后培养及实践能否获得，远端讨论预计毕业及后续职业发展的条件情景。三条主线的变化须按具体机制对齐这些时点，不预设固定政策周期、高校调整滞后或统一权重；高校招生、专业和培养调整仅作待核的交叉观察，不能单独证明职业趋势或录取机会。十年视野用于比较条件与改判信息，不构成确定预测，也不把情景数量当成功概率。

纯专题研究无需收集学生数据；只有任务进入具体个人应用时才使用必要且获准的个人条件。个人偏好改变选择权重，不改变公共事实；个人敏感资料留在受控本地。

## 六、覆盖规划：研究整个项目，不研究无限世界
建立[研究覆盖与推进表](../research/coverage.md)，分别检查：
- 产业及公共服务：既有重要领域、新兴方向、成熟改造、收缩退出；
- 人口：需求、供给、接续，队列、家庭及地区差异；
- 政策：问题历史、目标、工具、执行、反馈；
- 应用：任务、职业入口、成长转换、培养、个人适用；
- 时间空间：近期变化、中期传导、远期情景及目标地区。

这是查遗漏的多维视图，不是穷举笛卡尔积，不要求所有行业都有三线完整证据。行业分类用于核覆盖，职业分类用于连接任务，专业分类用于定位培养；不能互相替代。具体采用的分类标准须在使用时注明版本和合并映射，本轮不冒称已按某一最新官方目录全量映射。

优先次序由变化重要性、影响群体、决策敏感性、关键未知和取证成本共同决定，记录理由，不虚构评分公式。优先能改变路径比较的未知，而非最容易搜到或最热门的新闻。每轮从覆盖图选择一个连续问题的有界推进，串行完成独立性要求；不是一次派给一个代理所有行业。

已有少子化、碳转化、机器人、政策样本和视频素材形成起点，不能用其存在宣布各领域已覆盖。其他区域标“未评估/待研究”，不能凭没找到记录断言从未执行。

## 七、两种循环与改判传播
现实循环有时间延迟：例如人员接续困难改变企业组织，下期岗位和培养选择再改变供给。
研究循环是：提出有方向的判断→识别关键辨别信息→取证→改判→更新受影响选择。两个循环不得混成自证。

新材料到来后：
1. 核对来源是否新版本、口径是否兼容，定位受影响的判断版本。
2. 比较支持与反对信息；不是只搜支持原判断的材料。
3. 沿依赖关系检查下游，标明变化、待复核和可独立保留的分支。
4. 保留旧结论、当时依据、修改理由和时间；预测回看不能用事后信息改写旧预测。
5. 在当前入口更新版本；正式采用结论的变动按原协作流程审核。

局部前提失效不意味着整个研究链撤回；“独立”分支如共享融资、供给或制度前提也必须复核。未知可以限制结论，但不能掩盖逻辑断裂或偷换主体。

## 九、执行、审核与持续推进
知舟负责完整规划、任务目标、优先级和整体推进；本轮完整框架由知舟亲自设计。常规执行复用搜索、分析、审核三个 Chat Work 会话，职责清楚、每次有界单元；机械发布与合并使用独立角色运行。模型路由沿用主流程，不另行改变。

任务入口必须写清问题、所属链、需要改变的判断、允许输入和工具、预算、文件归属、依赖、验收与停止条件。已授权且无阻塞的下一步由协调者接续，不把派发、PR 或单次回复当完成；遇到超范围、必要批准或真实阻塞则说明具体边界，不能无声停止。

审核关注目标、实际证据、推导、分支、职业培养连接、版本和隐私。事实不足不自动拒绝条件推演；空泛中性结论、无条件夸大或只重复材料都不能替代分析。作者自检不是独审，哈希只证明内容一致，不证明执行真实或论证正确。

独立审核绑定成果 head；内容变更复核受影响部分，真实审核归档和最终差异由合并角色核验。精确 head 的指定检查、无阻断与平台要求均满足，且授权涵盖合并时才合并；不绕过保护、不用评论冒充平台批准。执行细节以[主流程](agent-workflow.md)为准。

## 十、完成标准与质量检查
**框架完成**：三线连续对象、跨线连接、职业培养个人应用、来源与判断、覆盖推进、版本更新、产物和角色有明确落点；模板能承接，入口不相互冲突，独立审核和仓库检查按实际版本通过。
**内容完成**：某个有界问题达到约定结论或明确的未决状态，关键连接可追溯；不等于全部领域填完。
**预测验证**：须等待相应现实观察并复核，不能用文档通过或模拟练习代替。
**软件完成**：若未来另行建设系统须另验收，本轮不声称自动采集、门禁或数据库已经部署。

已有五项合成检验覆盖供给与入口不同步、产品用途延后、机器人训练与招聘分离、政策跨期及培养个人连接。其收益是证明这些关系可表达，不证明现实趋势。完整版本还必须审核：
- 连续链能否容纳多个判断包，避免产业碎片化；
- 不同行业和公共服务能否使用同一核心记录而不强套商业利润链；
- 跨包引用与更新是否保留版本及受影响边界；
- 覆盖表是否帮助发现空白，而非固定几个实验为全局；
- 模板、导航和推进计划是否一致，新增任务不会误读旧暂停或旧分类；
- 个人应用、公共结论和权限是否真正分离。

## 十一、建设与填充的接续
本轮交付完整设计、配套模板、覆盖起点和导航衔接，提交一个可审核的完整变更，不再把“小范围试用框架”作为最终目标。
通过后按[建设计划](roadmap.md)开展实际填充：先建立覆盖概览和待解决问题，再按优先级深入连续链，接入真实职业及培养证据；不重复已经完成的方法试水，不一次性铺开无边界搜集。
工具只在出现重复负担并获得任务授权后建设。框架可以完整，执行仍分有界任务；分批执行不等于框架残缺，设计完整也不意味着信息已经齐备。
