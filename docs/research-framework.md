# 研究框架

## 定位

围绕“教育选择如何连接职业发展”开展研究，逐步形成可追溯的资料、分析和决策方法。
志愿填报是应用场景之一，研究范围也包括专业学习、升学、就业入口和长期发展。

研究顺序以[研究总图](research-architecture.md)为准：先理解中国政策、人口、产业与国际环境的历史和传导，再判断职业、培养路径及个人选择。下列四类是应用问题分类，不代表从学生兴趣反推公共事实。

## 四类研究问题

1. **招生与录取**：明确地区、科类或选科组合、批次、年份及统计口径，再比较数据。
2. **院校与专业**：比较培养方案、课程、实践条件、毕业要求与后续发展路径。
3. **行业与职业**：研究岗位任务、进入条件、能力要求、地域差异和职业迁移。
4. **个人决策**：在具体个人条件下比较可选路径，明确约束、取舍和仍需补充的信息。

以上是问题分类，不表示本项目已获得相应数据或结论。

## 每项研究的最小范围

- 一个可以明确回答的核心问题。
- 地区、时间范围、适用对象和术语口径。
- 可访问的输入材料、允许使用的工具和工作目录。
- 明确的交付文件、验收条件和停止条件。

## 证据与结论

优先寻找直接支撑问题的原始资料，例如发布机关的政策原文、学校培养方案、原始统计和岗位说明。
来源的权威性、直接性、时效性和适用范围分别判断，不用单一分数掩盖差异。

每条重要结论应能回答：依据是什么、原文在哪里、适用于谁、什么时候有效、还存在哪些限制。
来源冲突时保留各方口径；暂时无法解决的冲突记为待核实。
使用 Tavily Research/Search 时，执行[证据核验与调用边界](tavily-protocol.md)：综合输出和萃取不是原始证据的替代，关键主张经原文核查后才采用。

报告明确区分：

- **事实**：来源直接支持的陈述。
- **推断**：依据事实作出的分析，写清推理和假设。
- **建议**：针对具体条件的行动选项，说明取舍。

## 工作流程

提出问题 → 确定范围 → 收集并登记来源 → 整理数据 → 分析比较 → 核验结论 → 形成报告。

任务分工和提交使用 [Issue 与 PR 流程](agent-workflow.md)，独立核验使用[审核模块](../reviews/README.md)。报告生成、上传和审核建议采用是不同状态，在已授权范围内，合并由协调器核验后自动推进；超范围才交项目负责人。

每个阶段都可以记录“材料不足”并收缩问题；不为了填满报告而补造结论。
