# 历年位次与志愿竞争比较

## 用途与范围

在当年录取尚未发生时，为高三考生比较符合选科及其他资格条件的候选志愿；上游资格尚待核实的保留为条件候选，不当作满足或排除。使用当年分数、官方位次及可比的往年招生数据形成有条件的参考，不将往年最低分、最低位次或等位分当作今年的录取结果，也不把历史相似度转换成未经验证的录取概率。

## 按需输入

按省份、招生年份、考生类别、已选科目、成绩及官方位次确定比较范围；缺少当年位次时，查当年对应类别的官方逐分段数据，并核对成绩构成、排序类别、政策加分和同分排序口径是否适用；表中累计人数或同分区间不能当作个人精确官方位次，也不能还原同分排序。按具体招生渠道、批次、院校、专业组或专业定位计划，查询可取得的历年招生计划、投档与录取数据、当年的计划和规则。数据附发布主体、年份、指标定义和原文位置；未找到的字段保留未知，不推造。

## 比较步骤

1. 先核对可比性：同省份、考生类别、批次、渠道、院校与专业或专业组的对应关系是否一致；将投档线、院校录取线和专业录取线分开。发生组号、组内专业、招生人数、选科、办学地点或收费变化时记录影响；无法建立可靠映射的年份不强行比较。
2. 在口径可比的条件下，逐年并列考生位次、候选项历史最低录取或投档位次及计划数，以当年官方位次为固定参照，分别标明参照年与历史观察年；分列投档、院校录取及专业录取指标，缺失时不能互相替代，并说明差距方向。计划数须注明年份、招生单位和初始或调整后的发布阶段，实际录取人数另列。若仅有历史分数和该年的一分一段表，可在同省同类别同年口径下查对应累计位次或区间，记录同分、排序与数据限制；无法确认时标待核实。等位分可作为辅助理解，不能消除规则、招生计划和竞争变化。
3. 对当前计划与历史差异逐项说明：增加、减少、调整或缺失均不机械推导录取结果。已有多年数据可观察波动与异常；样本少、政策或招生结构变化大时扩大不确定性，不能把往年趋势视为今年阈值。
4. 用描述性梯度列候选项及其证据和不确定性，结合目标专业资格、分配和调剂范围、是否接受组内可能录取的专业、投档和退档规则及备选方案。专业组最低线不证明目标专业可达，不可接受的结果需单列。冲稳保只是沟通标签，不承诺概率或保底；填报排序和实际资格以当年省级规定、学校章程和计划为准。

## 与上下端连接

选科匹配模块排除已确认不符合条件的志愿，待核项保留；本模块处理历史竞争与当年可行性。政策、产业和人口三条上端主线持续研究，通过职业入口和实际培养路径与当前招生约束双向核对；按候选路径的相关性加载，不强制每一案例凑齐所有因素。上端约十年的条件情景须按实际培养路径对齐目标毕业／求职年份，不能与当前招生年混同。数据源、招生资格、未来情景等是分别核实的接口，不表示已建成完整数据库或预测系统。

## 暂不采纳的旧库结论

旧库提出按位次观察跨年变化与检查结构性变化，作为待研究方向保留；其固定系数、基于少量年份的漂移预测和具体录取概率缺乏本批独立回测与可靠适用范围，不作为填报算法。未核验的省份规则、学校数据及个人案例均不搬入。
