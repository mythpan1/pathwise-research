# 项目核心研究审查：第一批
日期：2026-10-30。基线：ce63e33c43d55800494401c820f509ed5332baf2。

## 目标与范围
面向高三考生，连接政策、产业和人口对约十年后就业的影响与省份、选科、分数位次、招生渠道、院校专业，经过培养与职业入口，形成 Agent 可按需组合检索并据条件提出具体方案的知识库。推导是主要工作方式，现有信息不足时形成有条件的判断并持续校准。

本批审读项目入口、研究方法、架构、框架、覆盖、计划、判断与链模板；审读连续研究中少子化、CO₂、机器人，以及十五五政策选材、六网、环保目录三个样本。研究导航和视频目录作为覆盖线索，21 个视频记录仅阅读开头及主要判断，未逐条核验来源。此为项目审查第一批，不是全部文件和证据审核。旧库吸收暂停，本批未读或吸收旧库。

## 可继承的内容
1. 政策、产业变迁、人口结构是可交叉的三条研究轴，不是三个固定行业；覆盖表已预留更广的实体产业、信息服务和公共服务。
2. 方法已明确先推演、关键节点求证，并保留方向和强弱，不能因未知停工。AGENTS.md 已在本基线强化推导先行与形成具体建议。
3. 三个连续案例已有可用的条件链：少子化向教育服务与新人入口传导、机器人从任务替代到入口压力、CO₂ 按商业化阶段与毕业时点比较训练方向。它们并非已经可直接给具体考生填报。
4. 行业、职业、专业和培养多对多，链模板保存版本与连接，可作为组合检索的基础。

## 发现的问题
1. **下端未落成。** 框架提及选科、成绩、资格、地域和培养，但本批未见能直接组合使用的分省及届别招生规则、普通志愿／强基／综评等渠道、历史投档与录取位次及院校专业比较链。data/README.md 规定数据默认不纳入版本管理，远端未见不等于本地没有数据。
2. **上下连接有机制，无完整决策闭环。** 案例已有产业或人口变化→任务→入口→培养推演，但缺少由具体考生条件筛选候选、历史位次推估和志愿方案的实际贯通。样本不能代替开放覆盖的市场判断。
3. **过度求证会削弱结果。** 少子化篇将备选出口要求训练、资格和雇主接受等全部接通后才计入实际备选；若在规划场景把这一要求当作“未核全就不比较”，会让条件方案停滞。应基于已知信息区分较可靠与条件备选，给当前倾向及改判条件；实际准入硬条件另核。CO₂、机器人篇有有方向的判断，不应笼统认定全部被防御性表述废掉。
4. **时间和市场需进一步展开。** 原框架设 2026—2036 窗口，案例也有商业化与毕业时钟；后续应对齐考生入学年、本科毕业、本硕毕业及工作初期，而非把十年作为笼统标签；研究范围要能覆盖不同领域和地区。
5. **偏题与旧规则。** 架构及少子化篇中的家庭照护与劳动参与主要属于宏观机制，并不是已给学生设置照护责任；应按用户主线检查是否需要保留，不能将学生家庭照护责任纳入规划输入。README、框架和架构仍把兴趣列为个人输入，与用户不将性格、画像及兴趣爱好纳入下端的最新要求不一致，需修订。入口仍含历史角色和流程表述，需按用户最新分工逐项梳理；授权文件须保留。
